### Day 1 — LangChain Architecture & Chat Models

#### Objectives
- Understand the LangChain ecosystem hierarchy
- Master Chat Model invocation (invoke, stream, batch, async)
- Understand the Runnable interface — the backbone of everything

#### LangChain Package Structure

```
LangChain Ecosystem:
├── langchain-core        ← Core abstractions (Runnable, BaseMessage)
├── langchain             ← Higher-level chains, agents, memory
├── langchain-community   ← 3rd party integrations (100+ tools, vector stores)
├── langchain-openai      ← OpenAI integration (ChatOpenAI, OpenAIEmbeddings)
├── langchain-anthropic   ← Anthropic integration (ChatAnthropic)
├── langgraph             ← Stateful multi-agent orchestration
└── langsmith             ← Observability, tracing, evaluation
```

**Core Design Principles:**
- **Composability:** Every component implements `Runnable` — chain with `|` operator
- **Provider Agnostic:** Swap GPT-4 for Claude with one line
- **Streaming First:** All components support `.stream()`, `.astream()`
- **Type Safety:** Pydantic-based input/output schemas

#### Chat Models

```python
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

# 1. Basic Chat Model Setup
llm = ChatOpenAI(
    model="gpt-4o",
    temperature=0.7,     # 0 = deterministic, 1 = creative
    max_tokens=2048,
    timeout=30,
    max_retries=2,
)

# 2. Invoke with messages
messages = [
    SystemMessage(content="You are a helpful Python expert."),
    HumanMessage(content="Explain decorators with a real-world example."),
]

response = llm.invoke(messages)
print(type(response))           # AIMessage
print(response.content)         # The actual text
print(response.usage_metadata)  # Token counts: input/output/total

# 3. Streaming — token by token
for chunk in llm.stream(messages):
    print(chunk.content, end="", flush=True)

# 4. Async invocation
import asyncio

async def ask_async():
    response = await llm.ainvoke(messages)
    return response.content

# 5. Batch processing — parallel calls
responses = llm.batch([
    [HumanMessage(content="What is Python?")],
    [HumanMessage(content="What is Rust?")],
    [HumanMessage(content="What is Go?")],
])
for r in responses:
    print(r.content[:100])

# 6. Multi-provider — identical interface
claude = ChatAnthropic(model="claude-3-5-sonnet-20241022", temperature=0)
response_claude = claude.invoke(messages)   # Same call!
```

#### The Runnable Interface — Core Abstraction

```python
from langchain_core.runnables import RunnableLambda, RunnablePassthrough

# Every component has these methods:
# .invoke(input)    -> sync single call
# .stream(input)    -> sync generator (token-by-token)
# .batch(inputs)    -> parallel calls
# .ainvoke(input)   -> async single call
# .astream(input)   -> async generator
# .abatch(inputs)   -> async parallel

runnable = RunnableLambda(str.upper)
print(runnable.invoke("hello"))   # HELLO

# Chain with | operator
chain = RunnableLambda(str.strip) | RunnableLambda(str.upper)
print(chain.invoke("  hello world  "))   # HELLO WORLD

passthrough = RunnablePassthrough()
print(passthrough.invoke({"key": "value"}))   # {"key": "value"} — unchanged
```

| Concept | Description | Example |
|---|---|---|
| `BaseMessage` | Base for all messages | `HumanMessage`, `AIMessage`, `SystemMessage` |
| `ChatModel` | LLM with chat interface | `ChatOpenAI`, `ChatAnthropic` |
| `Runnable` | Core composable interface | Every LangChain component |
| `invoke()` | Sync single call | Interactive apps |
| `stream()` | Token-by-token streaming | Chat UIs |
| `batch()` | Parallel calls | Bulk processing |

#### Output Parsers

```python
from langchain_core.output_parsers import StrOutputParser, JsonOutputParser
from langchain.output_parsers import PydanticOutputParser, CommaSeparatedListOutputParser
from pydantic import BaseModel, Field

# 1. StrOutputParser — AIMessage -> str
chain = template | llm | StrOutputParser()
result: str = chain.invoke({...})   # Pure string

# 2. PydanticOutputParser — structured JSON output
class CodeReview(BaseModel):
    score: int = Field(description="Code quality score 1-10")
    issues: list[str] = Field(description="List of issues found")
    suggestions: list[str] = Field(description="Improvement suggestions")
    verdict: str = Field(description="APPROVE, REQUEST_CHANGES, or NEEDS_WORK")

parser = PydanticOutputParser(pydantic_object=CodeReview)

review_template = ChatPromptTemplate.from_messages([
    ("system", "You are a senior code reviewer.\n{format_instructions}"),
    ("human", "Review this code:\n```python\n{code}\n```"),
])

chain = review_template | llm | parser
result: CodeReview = chain.invoke({
    "code": "def add(a,b): return a+b",
    "format_instructions": parser.get_format_instructions()
})
print(f"Score: {result.score}")
print(f"Issues: {result.issues}")
print(f"Verdict: {result.verdict}")

# 3. .with_structured_output() — easiest structured output approach
class Joke(BaseModel):
    setup:    str = Field(description="The question part of the joke")
    punchline: str = Field(description="The punchline")
    rating:   int = Field(description="Joke rating 1-10")

structured_llm = llm.with_structured_output(Joke)
joke: Joke = structured_llm.invoke("Tell me a programmer joke")
print(f"Q: {joke.setup}")
print(f"A: {joke.punchline}")

# 4. JsonOutputParser — streaming-friendly
json_parser = JsonOutputParser()
for partial in (template | llm | json_parser).stream({...}):
    print(partial)   # Partial dict that grows token by token

# 5. CommaSeparatedListOutputParser
list_parser = CommaSeparatedListOutputParser()
chain = ChatPromptTemplate.from_messages([
    ("human", "List 5 {type} languages separated by commas."),

# ['Haskell', 'Erlang', 'Clojure', 'F#', 'OCaml']
```

### Day 3 — LCEL (LangChain Expression Language) Mastery

#### Objectives
- Master all LCEL patterns: sequential, parallel, routing, assign
- Understand configurable chains for runtime customization
- Build complex multi-step pipelines using LCEL primitives

#### How LCEL Works — Mental Model

```
Input (dict)
    |
    v
ChatPromptTemplate      <- dict -> List[BaseMessage]
    |
    v
ChatModel (LLM)         <- List[BaseMessage] -> AIMessage
    |
    v
Output Parser           <- AIMessage -> str / dict / Pydantic
    |
    v
Final Output
```

#### LCEL Patterns

```python
from langchain_core.runnables import (
    RunnablePassthrough,
    RunnableParallel,
    RunnableLambda,
    RunnableBranch,
    ConfigurableField,
)
from operator import itemgetter

# Pattern 1: Sequential Chain (A -> B -> C)
translate_chain = translate_prompt | llm | StrOutputParser()
summarize_chain = summarize_prompt | llm | StrOutputParser()

# Chain them: translate first, then summarize the translation
combined = (
    translate_chain
    | (lambda text: {"text": text})   # str -> dict for next chain
    | summarize_chain
)

# Pattern 2: Parallel — both branches run simultaneously
analysis_chain = RunnableParallel(
    pros=pros_prompt | llm | StrOutputParser(),
    cons=cons_prompt | llm | StrOutputParser(),
    original=RunnablePassthrough(),         # Pass original input through
)
result = analysis_chain.invoke({"technology": "Kubernetes"})
# {"pros": "...", "cons": "...", "original": {"technology": "Kubernetes"}}

# Pattern 3: RunnablePassthrough.assign() — add keys without losing existing
enriched = RunnablePassthrough.assign(
    word_count=lambda x: len(x["text"].split()),
    char_count=lambda x: len(x["text"]),
    summary=summary_chain,   # Can be another chain!
)
result = enriched.invoke({"text": "Hello world"})
# {"text": "Hello world", "word_count": 2, "char_count": 11, "summary": "..."}

# Pattern 4: Dynamic Routing
def classify_intent(x: dict) -> str:
    q = x.get("question", "").lower()
    if any(w in q for w in ["code", "python", "function"]):
        return "code"
    elif any(w in q for w in ["math", "calculate"]):
        return "math"
    return "general"

router = RunnableBranch(
    (lambda x: classify_intent(x) == "code", code_expert_chain),
    (lambda x: classify_intent(x) == "math", math_expert_chain),
    general_chain,   # Default fallback
)

# Pattern 5: itemgetter — clean dict access
rag_chain = (
    {
        "context": itemgetter("documents") | format_docs,
        "question": itemgetter("question"),
    }
    | answer_prompt | llm | StrOutputParser()
)

# Pattern 6: Configurable at runtime
configurable_llm = ChatOpenAI(model="gpt-4o-mini").configurable_fields(
    temperature=ConfigurableField(id="temperature"),
    model=ConfigurableField(id="model_name"),
)

result1 = configurable_llm.invoke("Tell me a joke")   # Uses defaults
result2 = configurable_llm.with_config(
    configurable={"temperature": 0.9, "model_name": "gpt-4o"}
).invoke("Tell me a joke")   # Override at runtime!

# Pattern 7: Fallbacks — try primary, fall back on error
robust_chain = (prompt | gpt4_llm | StrOutputParser()).with_fallbacks([
    prompt | gpt4_mini_llm | StrOutputParser(),
    prompt | claude_llm | StrOutputParser(),
])

# Pattern 8: Retry
chain_with_retry = chain.with_retry(
    stop_after_attempt=3,
    wait_exponential_jitter=True,
)
```

#### Chat History with RunnableWithMessageHistory

```python
from langchain_core.chat_history import BaseChatMessageHistory, InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_openai import ChatOpenAI
from langchain_core.messages import trim_messages
from operator import itemgetter

# 1. In-Memory Store (Development)
store: dict[str, InMemoryChatMessageHistory] = {}

def get_session_history(session_id: str) -> BaseChatMessageHistory:
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

llm = ChatOpenAI(model="gpt-4o-mini")
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    MessagesPlaceholder(variable_name="history"),  # <-- history goes here
    ("human", "{input}"),
])

chain = prompt | llm
chain_with_history = RunnableWithMessageHistory(
    chain,
    get_session_history,
    input_messages_key="input",
    history_messages_key="history",
)

config = {"configurable": {"session_id": "user_vidhan_123"}}

r1 = chain_with_history.invoke({"input": "Hi, my name is Vidhan."}, config=config)
r2 = chain_with_history.invoke({"input": "What is my name?"}, config=config)
# r2 correctly says "Vidhan" because history is auto-managed!

# 2. Redis (Production — survives restarts)
from langchain_community.chat_message_histories import RedisChatMessageHistory

def get_redis_history(session_id: str) -> RedisChatMessageHistory:
    return RedisChatMessageHistory(
        session_id=session_id,
        url="redis://localhost:6379",
        ttl=86400,   # 24-hour auto-expiry
    )

# 3. PostgreSQL (Enterprise)
from langchain_community.chat_message_histories import PostgresChatMessageHistory

def get_postgres_history(session_id: str) -> PostgresChatMessageHistory:
    return PostgresChatMessageHistory(
        connection_string="postgresql://user:pass@localhost/mydb",
        session_id=session_id,
    )

# 4. Token Budget Management
trimmer = trim_messages(
    max_tokens=4000,        # Stay within LLM context window
    strategy="last",        # Keep the most recent messages
    token_counter=llm,      # Use LLM tokenizer for accurate counts
    include_system=True,    # Always keep system message
    allow_partial=False,
    start_on="human",
)

trimmed_chain = (
    RunnablePassthrough.assign(history=itemgetter("history") | trimmer)
    | prompt | llm
)

# 5. Summary Memory — compress old messages to save tokens
from langchain_core.messages import SystemMessage
from langchain_core.output_parsers import StrOutputParser

summary_prompt = ChatPromptTemplate.from_messages([
    ("system", "Summarize this conversation in 2 sentences:"),
    ("human", "{conversation}"),
])

def compress_history(messages: list, threshold: int = 10) -> list:
    if len(messages) <= threshold:
        return messages
    old = messages[:-threshold]
    recent = messages[-threshold:]
    conv = "\n".join([f"{m.type}: {m.content}" for m in old])
    summary = (summary_prompt | llm | StrOutputParser()).invoke({"conversation": conv})
    return [SystemMessage(content=f"Previous conversation: {summary}")] + recent
```

| Memory Type | Persistence | Token Cost | Best For |
|---|---|---|---|
| `InMemoryChatMessageHistory` | No | Full history | Development |
| Window (last N messages) | No | Medium | Simple chatbots |
| Summary compression | No | Low | Long conversations |
| Redis | Yes | Configurable | Production |
| PostgreSQL | Yes | Configurable | Enterprise |

```python
from langchain_core.document_loaders import BaseLoader
from typing import Iterator
import sqlalchemy

class DatabaseLoader(BaseLoader):
    def __init__(self, connection_string: str, query: str):
        self.conn_str = connection_string
        self.query = query

    def lazy_load(self) -> Iterator[Document]:
        engine = sqlalchemy.create_engine(self.conn_str)
        with engine.connect() as conn:
            for row in conn.execute(sqlalchemy.text(self.query)):
                yield Document(
                    page_content=row["content"],
                    metadata={"id": row["id"], "source": "database"}
                )
```

#### Text Splitters

```python
from langchain_text_splitters import (
    RecursiveCharacterTextSplitter,
    TokenTextSplitter,
    MarkdownHeaderTextSplitter,
    SemanticChunker,
)

# 1. RecursiveCharacterTextSplitter — THE default choice
# Tries separators in order: paragraph -> sentence -> word -> character
splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,          # Target chars per chunk
    chunk_overlap=200,        # Overlap for context continuity
    length_function=len,
    separators=["\n\n", "\n", ". ", " ", ""],
)
chunks = splitter.split_documents(docs)
print(f"Docs: {len(docs)}, Chunks: {len(chunks)}")

# 2. TokenTextSplitter — split by actual tokens (more precise)
token_splitter = TokenTextSplitter(chunk_size=512, chunk_overlap=50)

# 3. MarkdownHeaderTextSplitter — structure-aware, respects document hierarchy
md_splitter = MarkdownHeaderTextSplitter(
    headers_to_split_on=[("#", "h1"), ("##", "h2"), ("###", "h3")],
    strip_headers=False,
)
splits = md_splitter.split_text(md_content)
# Each split carries metadata: {"h1": "Chapter 1", "h2": "Section 1.1"}

# 4. SemanticChunker — AI-powered, groups semantically related sentences
from langchain_openai import OpenAIEmbeddings

semantic_splitter = SemanticChunker(
    embeddings=OpenAIEmbeddings(),
    breakpoint_threshold_type="percentile",
    breakpoint_threshold_amount=95,
)

# 5. Production Pipeline
def ingest_document(file_path: str, chunk_size: int = 1000) -> list[Document]:
    # Load
    if file_path.endswith(".pdf"):
        loader = PyPDFLoader(file_path)
    elif file_path.endswith(".md"):
        loader = UnstructuredMarkdownLoader(file_path)
    else:
        loader = TextLoader(file_path)
    raw_docs = loader.load()
    
    # Split
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_size // 5,   # 20% overlap
    )
    chunks = splitter.split_documents(raw_docs)
    
    # Enrich metadata
    for i, chunk in enumerate(chunks):
        chunk.metadata.update({"chunk_index": i, "total_chunks": len(chunks)})
    
    return chunks
```

| Content Type | Chunk Size | Overlap | Rationale |
|---|---|---|---|
| Code files | 500-1000 chars | 100 | Functions as natural boundaries |
| Academic papers | 1000-1500 chars | 200 | Dense information density |
| Web articles | 800-1200 chars | 150 | Mixed paragraph lengths |
| Legal documents | 1500-2000 chars | 300 | Heavy context dependency |
| Conversations | 256-512 chars | 50 | Short exchanges |

```python
from langchain_community.embeddings import HuggingFaceEmbeddings
import numpy as np

# 1. OpenAI Embeddings
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",   # 3072 dims, highest quality
    # model="text-embedding-3-small", # Cheaper, 1536 dims
    dimensions=1536,                   # Optional dimension reduction
)

query_vector = embeddings.embed_query("What is machine learning?")
print(f"Dimensions: {len(query_vector)}")   # 1536

doc_vectors = embeddings.embed_documents(["Doc 1...", "Doc 2...", "Doc 3..."])

# Cosine similarity — close to 1 means similar meaning
def cosine_sim(v1, v2):
    v1, v2 = np.array(v1), np.array(v2)
    return float(np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2)))

print(cosine_sim(query_vector, doc_vectors[0]))   # e.g., 0.87

# 2. Local/Free Embeddings (HuggingFace)
```

### Day 7 — Building RAG Systems

#### Objectives
- Build complete end-to-end RAG pipelines
- Implement HyDE, contextual compression, parent-document retrieval
- Evaluate RAG quality with RAGAS

#### RAG Architecture

```
Query
  |
  v
[Query Rewriting]  <- Improve retrieval with better query formulations
  |
  v
[Vector Retrieval] <- Find relevant document chunks
  |
  v
[Reranking]        <- Re-order by true relevance to query
  |
  v
[Context Assembly] <- Format context string for LLM
  |
  v
[LLM Generation]   <- Generate answer grounded in retrieved context
```

```python
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.vectorstores import Chroma
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough, RunnableParallel
from operator import itemgetter

llm = ChatOpenAI(model="gpt-4o", temperature=0)
embeddings = OpenAIEmbeddings()
vectorstore = Chroma(persist_directory="./chroma_db", embedding_function=embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 4})

def format_docs(docs: list) -> str:
    return "\n\n---\n\n".join([
        f"[Source: {doc.metadata.get('source', 'Unknown')}]\n{doc.page_content}"
        for doc in docs
    ])

# 1. Simple RAG Chain
rag_prompt = ChatPromptTemplate.from_messages([
    ("system", """Answer questions using ONLY the provided context.
If the context doesn't contain the answer, say "I don't have that information."
Always cite your source file.

Context:
{context}"""),
    ("human", "{question}"),
])

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt | llm | StrOutputParser()
)

answer = rag_chain.invoke("What is the main architecture?")

# 2. RAG with Sources
rag_with_sources = (
    RunnableParallel(
        context=retriever | format_docs,
        question=RunnablePassthrough(),
        source_docs=retriever,
    )
    | {
        "answer": rag_prompt | llm | StrOutputParser(),
        "source_docs": itemgetter("source_docs"),
    }
)

result = rag_with_sources.invoke("How does caching work?")
print(result["answer"])
print([d.metadata["source"] for d in result["source_docs"]])

# 3. HyDE — Hypothetical Document Embeddings
# Insight: generate a hypothetical ANSWER, then retrieve docs similar to it.
# This dramatically improves retrieval for complex, abstract queries.

hyde_prompt = ChatPromptTemplate.from_messages([
    ("human", "Write a detailed passage that would perfectly answer: {question}"),
])

def hyde_retrieve(question: str) -> list:
    # Step 1: Generate hypothetical document
    hypo_doc = (hyde_prompt | llm | StrOutputParser()).invoke({"question": question})
    # Step 2: Retrieve docs similar to the hypothetical doc (NOT the original question)
    return retriever.invoke(hypo_doc)

# 4. Contextual Compression — extract only relevant parts of each doc
from langchain.retrievers.document_compressors import LLMChainExtractor
from langchain.retrievers import ContextualCompressionRetriever

compressor = LLMChainExtractor.from_llm(llm)
compression_retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=retriever,
)

# 5. Parent Document Retriever
# Index small chunks for precision, return large parent docs for context
from langchain.retrievers import ParentDocumentRetriever
from langchain_community.storage import InMemoryStore
from langchain_text_splitters import RecursiveCharacterTextSplitter

parent_retriever = ParentDocumentRetriever(
    vectorstore=vectorstore,
    docstore=InMemoryStore(),
    child_splitter=RecursiveCharacterTextSplitter(chunk_size=400),
    parent_splitter=RecursiveCharacterTextSplitter(chunk_size=2000),
)
parent_retriever.add_documents(documents)
```

| RAG Failure Mode | Symptom | Solution |
|---|---|---|
| Bad retrieval | Wrong docs returned | Multi-query retriever, HyDE |
| Lost-in-middle | Ignores middle chunks | Reranking, limit to 4 chunks |
| Hallucination | Answer not in context | Strict prompt, faithfulness check |
| Stale data | Outdated answers | Incremental indexing, TTL |
| Query-doc mismatch | Short query vs long docs | Query expansion, HyDE |
| Too much context | LLM confused | Contextual compression |

```python
# 1. @tool decorator — simplest approach
@tool
def search_web(query: str) -> str:
    """Search the web for current information. Use for recent events or news.

    Args:
        query: The search query string

    Returns:
        Search results as a JSON string
    """
    from tavily import TavilyClient
    results = TavilyClient(api_key="...").search(query, max_results=5)
    return json.dumps(results["results"], indent=2)

# 2. Typed Input Schema — for complex inputs
class StockInput(BaseModel):
    symbol: str = Field(description="Stock ticker symbol, e.g. 'AAPL'")
    period: str = Field(default="1mo", description="Period: '1d', '5d', '1mo', '1y'")
    include_volume: bool = Field(default=True, description="Include volume data")

@tool(args_schema=StockInput)
def get_stock_data(symbol: str, period: str = "1mo", include_volume: bool = True) -> str:
    """Get historical stock price data for a ticker symbol."""
    import yfinance as yf
    hist = yf.Ticker(symbol).history(period=period)
    data = {
        "symbol": symbol,
        "current_price": round(float(hist["Close"].iloc[-1]), 2),
        "change_pct": round(((hist["Close"].iloc[-1]/hist["Close"].iloc[0]) - 1) * 100, 2),
    }
    if include_volume:
        data["avg_volume"] = int(hist["Volume"].mean())
    return json.dumps(data)

# 3. BaseTool — full control over behavior
class SQLQueryTool(BaseTool):
    name: str = "query_database"
    description: str = """Execute read-only SQL SELECT queries against the analytics database.
    Only use for data retrieval — no INSERT, UPDATE, or DELETE allowed."""

    def _run(self, query: str) -> str:
        if not query.strip().upper().startswith("SELECT"):
            return "Error: Only SELECT statements are allowed for safety."
        # Execute safely using your DB connection
        import sqlalchemy
        engine = sqlalchemy.create_engine("postgresql://...")
        with engine.connect() as conn:
            result = conn.execute(sqlalchemy.text(query))
            rows = [dict(row) for row in result]
            return json.dumps(rows[:100])   # Limit output

    async def _arun(self, query: str) -> str:
        return self._run(query)   # Or use asyncpg for true async

# 4. Bind tools to LLM — LLM can now call them
llm = ChatOpenAI(model="gpt-4o", temperature=0)
tools = [search_web, get_stock_data, SQLQueryTool()]
llm_with_tools = llm.bind_tools(tools)

response = llm_with_tools.invoke("What is Apple's current stock price?")
print(response.content)       # "" — empty when tool called
print(response.tool_calls)    # [{"name": "get_stock_data", "args": {"symbol": "AAPL"}, "id": "..."}]

# 5. Execute tool calls and get final answer
tools_map = {t.name: t for t in tools}

def execute_tool_calls(ai_msg) -> list[ToolMessage]:
    results = []
    for tc in ai_msg.tool_calls:
        try:
            output = tools_map[tc["name"]].invoke(tc["args"])
        except Exception as e:
            output = f"Tool error: {str(e)}"
        results.append(ToolMessage(content=str(output), tool_call_id=tc["id"]))
    return results

# Full agentic tool loop
msgs = [HumanMessage(content="What is Apple's current stock price?")]
ai_msg = llm_with_tools.invoke(msgs)          # Step 1: LLM decides to use tool
tool_msgs = execute_tool_calls(ai_msg)         # Step 2: Execute the tool call
final = llm_with_tools.invoke(msgs + [ai_msg] + tool_msgs)  # Step 3: LLM summarizes
print(final.content)
```

### Day 9 — ReAct Agents

#### Objectives
- Understand the ReAct (Reasoning + Acting) loop pattern
- Build agents with AgentExecutor
- Add memory, custom prompts, and async streaming

#### ReAct Pattern Explained

```
ReAct Loop (cycles until confident):

1. THOUGHT:  LLM reasons about what information it needs
2. ACTION:   LLM selects a tool and provides arguments
3. OBSERVATION: Tool executes and returns results
4. -> Back to THOUGHT with new information

When LLM has enough info -> FINAL ANSWER
```

```python
from langchain.agents import create_react_agent, AgentExecutor

from langchain_openai import ChatOpenAI

    agent=agent,
```

```python
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.outputs import LLMResult
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import time, json

# 1. Custom Production Callback
class ProductionMonitor(BaseCallbackHandler):
    def __init__(self, service_name: str):
        self.service = service_name
        self._start_time = None

    def on_llm_start(self, serialized, prompts, **kwargs):
        self._start_time = time.time()
        model = serialized.get("name", "unknown")
        print(f"[{self.service}] LLM started | model={model}")

    def on_llm_end(self, response: LLMResult, **kwargs):
        latency = (time.time() - self._start_time) * 1000
        tokens = {}
        if response.llm_output:
            tokens = response.llm_output.get("token_usage", {})
        print(f"[{self.service}] LLM done | {latency:.0f}ms | tokens={tokens}")
        # Send to Prometheus / DataDog / CloudWatch here

    def on_llm_error(self, error, **kwargs):
        print(f"[{self.service}] ERROR: {error}")
        # Send PagerDuty alert or Slack notification

    def on_tool_start(self, serialized, input_str, **kwargs):
        tool_name = serialized.get("name", "unknown")
        print(f"[{self.service}] Tool call: {tool_name} | input: {input_str[:100]}")

# Attach to any chain
monitor = ProductionMonitor("rag-service")
response = llm.invoke(messages, config={"callbacks": [monitor]})
# OR make it permanent on the chain:
monitored_chain = chain.with_config(callbacks=[monitor])

# 2. FastAPI SSE Streaming Endpoint
app = FastAPI()

@app.post("/chat/stream")
async def stream_chat(question: str):
    async def generate():
        async for chunk in chain.astream({"input": question}):
            content = chunk if isinstance(chunk, str) else getattr(chunk, "content", "")
            if content:
                yield f"data: {json.dumps({'token': content})}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(
        generate(),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )

# 3. WebSocket Real-time Agent
from fastapi import WebSocket

@app.websocket("/ws/chat/{session_id}")
async def websocket_chat(websocket: WebSocket, session_id: str):
    await websocket.accept()
    config = {"configurable": {"session_id": session_id}}

    try:
        while True:
            data = await websocket.receive_json()
            question = data["message"]

            async for event in agent.astream_events(
                {"messages": [HumanMessage(content=question)]},
                config=config, version="v2",

                if event["event"] == "on_chat_model_stream":
                    token = event["data"]["chunk"].content

                elif event["event"] == "on_tool_start":
                    await websocket.send_json({"type": "tool_start", "tool": event["name"]})

            await websocket.send_json({"type": "done"})
```
