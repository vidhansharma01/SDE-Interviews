### 🧩 What is Tokenization?

**Tokenization** is the process of converting raw text into a sequence of discrete units (**tokens**) that a model can process. It sits between raw text and the numerical embedding layer.

```
Raw Text → [Tokenizer] → Token Sequence → [Embedding Layer] → Vectors → [Model]

"Don't tokenize blindly." → ["Don", "'t", "token", "ize", "blind", "ly", "."]
                         →  [12,    45,   9823,    654,   3341,    89,    7]
                         →  [[0.1, 0.3...], [0.5, 0.2...], ...]    ← 768-dim vectors
```

---

### 📊 The Full Taxonomy

```
Tokenization
├── Word-Level
│   ├── Whitespace splitting
│   ├── Punctuation-aware (NLTK word_tokenize)
│   └── Rule-based (regex)
│
├── Subword-Level  ← Dominant in modern NLP
│   ├── Byte Pair Encoding (BPE) → GPT-2, GPT-4, RoBERTa
│   ├── WordPiece               → BERT, DistilBERT, ALBERT
│   ├── Unigram Language Model  → XLNet, ALBERT (alt)
│   └── SentencePiece           → LLaMA, T5, Gemma (framework, not algorithm)
│
├── Character-Level
│   ├── Single character tokens
│   └── Morpheme-aware splitting
│
└── Byte-Level
    ├── Raw UTF-8 bytes (0–255 vocabulary)
    └── Byte-level BPE → GPT-2 (byte vocab + merges)
```

---

### ⚖️ Key Trade-Off Axes

Every tokenization choice lives on these four axes:

```
1. VOCABULARY SIZE
   Small vocab ←────────────────────────────────→ Large vocab
   (char: 256)                                    (word: 50,000+)
   • Small: more tokens per sentence, harder for model to learn patterns
   • Large: OOV words, poor generalization, memory cost

2. SEQUENCE LENGTH
   Short sequences ←───────────────────────────→ Long sequences
   (word-level)                                   (char-level)
   • Short: efficient attention (O(n²)), but vocabulary must be large
   • Long: any text representable, but attention cost explodes

3. LINGUISTIC AWARENESS
   Linguistically naive ←─────────────────────→ Linguistically rich
   (byte-level)                                  (morpheme-based)
   • Naive: language-agnostic, works for any language
   • Rich: captures morphology, but requires language-specific rules

4. OOV HANDLING
   Poor OOV ←────────────────────────────────→ Zero OOV
   (word-level)                                  (byte-level)
   • Word-level: unknown words → [UNK], semantic loss
   • Byte-level: every string representable (no unknowns ever)
```

| Algorithm | Vocab Size | Seq Length | OOV | Used By |
|---|---|---|---|---|
| Word-level | 20K–500K | Short | Yes | Old-school NLP, FastText |
| Character-level | 100–1K | Very Long | No | Some language models |

| Unigram LM | 8K–32K | Medium | No | XLNet, mBART |
| SentencePiece + BPE | 32K | Medium | No | LLaMA, T5, Gemma, Mistral |

#### Strategy 2: Regex-Based Tokenization

```python
import re

def regex_tokenize(text: str) -> list[str]:
    """
    Split on word boundaries, preserving contractions.
    Pattern: words, contractions, or individual punctuation marks.
    """
    # Pattern used by GPT-2 (simplified)
    pattern = r"""'s|'t|'re|'ve|'m|'ll|'d| ?\w+| ?[^\s\w]+|\s+"""
    return re.findall(pattern, text.lower())

text = "I don't think that's right, do you?"
print(regex_tokenize(text))
# ["i", " don", "'t", " think", " that", "'s", " right", ",", " do", " you", "?"]
```

### 🏗️ Building a Word-Level Vocabulary

```python
from collections import Counter
from typing import List, Dict, Optional
import re

class WordLevelTokenizer:
    """
    A complete word-level tokenizer with vocabulary management.
    Demonstrates all the problems with word-level tokenization.
    """
    SPECIAL_TOKENS = {
        '[PAD]': 0,     # Padding
        '[UNK]': 1,     # Unknown
        '[CLS]': 2,     # Classification token (BERT-style)
        '[SEP]': 3,     # Separator
        '[MASK]': 4,    # Masking token
    }

    def __init__(self, max_vocab_size: int = 50_000, min_freq: int = 2):
        self.max_vocab_size = max_vocab_size
        self.min_freq       = min_freq
        self.word2idx: Dict[str, int] = {}
        self.idx2word: Dict[int, str] = {}
        self.word_freq: Counter = Counter()

    def _tokenize_raw(self, text: str) -> List[str]:
        """Simple word tokenization: lowercase + split on non-alphanumeric."""
        text = text.lower()
        tokens = re.findall(r"\b\w+(?:'\w+)?\b|[^\w\s]", text)
        return tokens

    def build_vocab(self, corpus: List[str]) -> None:
        """
        Build vocabulary from a corpus of texts.
        Applies:
          1. Min frequency filtering
          2. Max vocab size cap (keep most frequent)
          3. Special token insertion
        """
        # Count word frequencies
        for text in corpus:
            tokens = self._tokenize_raw(text)
            self.word_freq.update(tokens)

        # Filter by frequency
        filtered = {w: c for w, c in self.word_freq.items() if c >= self.min_freq}

        # Sort by frequency, take top N
        sorted_words = sorted(filtered.items(), key=lambda x: -x[1])
        top_words = [w for w, _ in sorted_words[:self.max_vocab_size - len(self.SPECIAL_TOKENS)]]

        # Build mappings
        self.word2idx = dict(self.SPECIAL_TOKENS)
        for word in top_words:
            self.word2idx[word] = len(self.word2idx)
        self.idx2word = {v: k for k, v in self.word2idx.items()}

        print(f"Vocabulary built: {len(self.word2idx):,} tokens")
        print(f"Words seen:       {len(self.word_freq):,} unique words")
        print(f"OOV words:        {len(self.word_freq) - len(top_words):,} (below min_freq or cap)")

    def encode(self, text: str) -> List[int]:
        tokens = self._tokenize_raw(text)
        ids = [self.word2idx.get(t, self.SPECIAL_TOKENS['[UNK]']) for t in tokens]
        unk_count = sum(1 for i in ids if i == self.SPECIAL_TOKENS['[UNK]'])
        if unk_count:
            print(f"  ⚠️  {unk_count}/{len(ids)} tokens mapped to [UNK]")
        return ids

    def decode(self, ids: List[int]) -> str:
        return ' '.join(self.idx2word.get(i, '[UNK]') for i in ids)


# ── Demonstration ─────────────────────────────────────────────────────
corpus = [
    "The quick brown fox jumps over the lazy dog.",
    "Machine learning is a subset of artificial intelligence.",
    "Natural language processing enables computers to understand text.",
    "Deep learning models require large amounts of training data.",
    "The fox was very quick and very brown.",
] * 100  # Simulate a real corpus

tokenizer = WordLevelTokenizer(max_vocab_size=1000, min_freq=2)
tokenizer.build_vocab(corpus)

# Encode familiar text
ids = tokenizer.encode("Machine learning requires large data.")
print("Encoded:", ids)
print("Decoded:", tokenizer.decode(ids))

# Encode text with OOV words
ids_oov = tokenizer.encode("Tokenization and NLP are fascinating fields of AI research.")
# → "Tokenization", "NLP", "AI", "research" likely mapped to [UNK]
```

### 💀 The OOV Problem — Why Word-Level Fails

```python
# Problem 1: Vocabulary Explosion
# Shakespeare's works: ~29,000 unique words
# English Wikipedia: ~3,000,000 unique words
# The Internet: practically infinite

# Problem 2: Morphological Variants
# "run", "runs", "ran", "running", "runner", "runners" → 6 separate vocab entries
# In German: one word can have 30+ inflections → vocabulary explodes even faster

# Problem 3: Named Entities & Technical Terms
bad_cases = [
    "COVID-19",              # New words after training cutoff
    "ChatGPT",               # Product names
    "antidisestablishmentarianism",  # Rare long words
    "Supercalifragilisticexpialidocious",  # Made-up words
    "2024年",                # Mixed script text
    "C++",                   # Code
    "🤖",                    # Emoji
]
# ALL of these → [UNK] in a word-level tokenizer

# Problem 4: The UNK collapse
# Multiple different unknown words all become identical [UNK] tokens
# The model CANNOT distinguish "ChatGPT" from "antidisestablishmentarianism"
# It sees the same embedding for both!

print("Word-level tokenization fails on:")
for case in bad_cases:
    print(f"  '{case}' → [UNK]")
```

### ✅ When Word-Level Still Makes Sense

```python
# FastText — word-level but uses character n-grams internally
# Handles OOV by composing from character n-grams
# Good for morphologically rich languages

# Named Entity Recognition with small, fixed domain vocabulary
# Medical coding: ICD-10 codes are word-level tokens
# Stock tickers: AAPL, GOOG, etc.

# Rule of thumb:
# Use word-level when:
#   ✓ Domain vocabulary is small and fixed (<10K words)
#   ✓ No OOV risk (controlled input)
#   ✓ Language is morphologically simple (isolating languages like Mandarin, Vietnamese)
#   ✓ Pre-2017 NLP systems (for compatibility)
```

### 🔤 Character-Level Tokenization

```python
class CharacterTokenizer:
    """
    Tokenizes text into individual characters.
    Vocabulary is the set of all observed characters.
    """
    def __init__(self):
        self.char2idx: dict = {}
        self.idx2char: dict = {}
        # Common special tokens
        self.PAD, self.UNK, self.BOS, self.EOS = 0, 1, 2, 3
        self._init_specials()

    def _init_specials(self):
        for idx, tok in enumerate(['[PAD]', '[UNK]', '[BOS]', '[EOS]']):
            self.char2idx[tok] = idx
            self.idx2char[idx] = tok

    def build_vocab(self, texts: list[str]) -> None:
        """Collect all unique characters."""
        unique_chars = sorted(set(''.join(texts)))
        for char in unique_chars:
            if char not in self.char2idx:
                idx = len(self.char2idx)
                self.char2idx[char] = idx
                self.idx2char[idx] = char
        print(f"Character vocab size: {len(self.char2idx)}")

    def encode(self, text: str, add_special=True) -> list[int]:
        ids = [self.char2idx.get(c, self.UNK) for c in text]
        if add_special:
            ids = [self.BOS] + ids + [self.EOS]
        return ids

    def decode(self, ids: list[int]) -> str:
        return ''.join(
            self.idx2char.get(i, '[UNK]') for i in ids
            if i not in {self.PAD, self.BOS, self.EOS}
        )


# ── Properties of character tokenization ─────────────────────────────
tok = CharacterTokenizer()
texts = ["hello world", "ChatGPT's tokenization!", "Héllo Wörld"]
tok.build_vocab(texts)

for text in texts:
    encoded = tok.encode(text)
    print(f"'{text}'")
    print(f"  Chars ({len(encoded)}): {encoded}")
    print(f"  Decoded: '{tok.decode(encoded)}'")

# "ChatGPT's tokenization!" → 24 character tokens
# "hello" → 5 character tokens   (vs 1 word token)

# Vocab sizes in practice:
# English text:       ~100-200 characters
# Full Unicode (BMP):  65,536 code points
# All Unicode:        143,924 characters
```

### 📐 Character-Level Sequence Length Problem

```python
# The brutal math:
#   Average English word length ≈ 5 characters
#   Average word-level token ≈ 1
#   Average BPE token ≈ 1.3 words (subword compression)
#
#   For a 512 word document:
#     Word-level:  ~512 tokens
#     BPE:         ~640 tokens
#     Char-level: ~2,560 tokens  ← 5x more tokens!
#
#   Transformer attention is O(n²):
#     512² = 262,144 operations
#   2,560² = 6,553,600 operations  ← 25x more computation!

def compare_sequence_lengths(text: str, char_tok, bpe_tok):
    char_len = len(char_tok.encode(text))
    bpe_len  = len(bpe_tok.encode(text))
    print(f"Text length (chars):      {len(text)}")
    print(f"Character tokens:         {char_len}")
    print(f"BPE tokens:               {bpe_len}")
    print(f"Char/BPE ratio:           {char_len/bpe_len:.1f}x longer")
```

### 💾 Byte-Level Tokenization

```python
class ByteLevelTokenizer:
    """
    Tokenizes text into UTF-8 bytes.
    Vocabulary is always exactly 256 (one per byte value 0-255).
    ZERO out-of-vocabulary words — ever.
    """
    def __init__(self):
        # Fixed vocabulary: 256 bytes + special tokens
        self.vocab_size = 256 + 4
        self.PAD, self.UNK, self.BOS, self.EOS = 256, 257, 258, 259

    def encode(self, text: str, add_special=True) -> list[int]:
        """Convert text to UTF-8 bytes."""
        byte_ids = list(text.encode('utf-8'))   # Python bytes → list of ints (0-255)
        if add_special:
            byte_ids = [self.BOS] + byte_ids + [self.EOS]
        return byte_ids

    def decode(self, ids: list[int]) -> str:
        """Convert byte IDs back to string."""
        byte_vals = [i for i in ids if i < 256]   # filter special tokens
        return bytes(byte_vals).decode('utf-8', errors='replace')

    def vocab_size_info(self):
        print(f"Fixed vocab size: {self.vocab_size} (256 bytes + 4 specials)")
        print(f"OOV rate: 0% guaranteed — every UTF-8 string is encodable")


# ── Byte-level properties ─────────────────────────────────────────────
btok = ByteLevelTokenizer()

examples = [
    ("English", "Hello World"),

    ("Math",    "∑ᵢ xᵢ² + √(y)"),
]

print("Byte-Level Tokenization:\n")

    print(f"             | Bytes: {ids[1:-1]}")   # Skip BOS/EOS
```

### 🌍 UTF-8 Encoding — Why Bytes Work Across Languages

```python
# UTF-8 is a variable-length encoding:
# - ASCII chars (a-z, 0-9):    1 byte  each
# - Latin extended (é, ñ):     2 bytes each
# - Chinese, Arabic, etc.:     3 bytes each
# - Emoji (🤖):                4 bytes each

def show_utf8_encoding(text: str):
    print(f"Text: '{text}'")
    encoded = text.encode('utf-8')
    for char in text:
        char_bytes = char.encode('utf-8')
        print(f"  '{char}' → {list(char_bytes)} ({len(char_bytes)} byte(s))")
    print(f"Total: {len(encoded)} bytes for {len(text)} characters\n")

show_utf8_encoding("Hi 🤖!")
# 'H' → [72]          (1 byte)
# 'i' → [105]         (1 byte)
# ' ' → [32]          (1 byte)
# '🤖' → [240, 159, 164, 150]  (4 bytes)
# '!' → [33]          (1 byte)
# Total: 8 bytes for 5 characters

# Key insight: emoji and CJK characters cost 3-4 bytes each
# This is why GPT-4's token count for Chinese text is high
```

### 💡 The Subword Insight

The key insight (Sennrich et al., 2015) is:

> **Frequent words should be kept whole. Rare words should be split into meaningful pieces.**

```
Word-level:   "unbelievable" → [UNK]                ← complete loss of meaning
Char-level:   "unbelievable" → ['u','n','b','e',...] ← 12 tokens
Subword:      "unbelievable" → ["un", "believ", "able"] ← 3 tokens + morphology preserved!

The magic:
  "un"      is a known prefix (negation)
  "believ"  is the root
  "able"    is a known suffix (capable of)
  → Model can generalize "un + [anything] + able" even for unseen words!
```

---

### 📐 Two Phases in Subword Tokenization

```
Phase 1: VOCABULARY LEARNING (offline, once before training)
─────────────────────────────────────────────────────────────
Input:  Large text corpus
Process: Run BPE/WordPiece/Unigram algorithm on corpus statistics
Output: A fixed vocabulary of V subword tokens

Phase 2: TEXT SEGMENTATION (online, at inference time)
──────────────────────────────────────────────────────
Input:  Any text string
Process: Apply the learned vocabulary to greedily segment the text
Output: A sequence of token IDs from the vocabulary
```

### 🔗 Common Interface: The Tokenizer Contract

```python
from transformers import AutoTokenizer

class SubwordTokenizerInterface:
    """
    All subword tokenizers (BPE, WordPiece, SentencePiece)
    expose this same core interface.
    """
```

### 📖 BPE History & Intuition

Originally a **data compression algorithm** (Philip Gage, 1994), adapted for NLP by Sennrich et al. (2015).

**Core idea:** Find the most frequent pair of consecutive symbols, merge them into a new symbol, repeat.

```
Compression example:
  "aaabdaaabac" with pairs:
  Step 1: "aa" appears 4 times → replace with "Z": "ZabdZabac"
  Step 2: "Za" appears 2 times → replace with "Y": "YbdYbac"
  ...

NLP adaptation:
  Start with character vocabulary
  Repeatedly merge most frequent adjacent pairs
  Stop at target vocabulary size
```

### 💻 BPE Algorithm from Scratch

```python
from collections import Counter, defaultdict
from typing import Dict, List, Tuple
import re

class BPETokenizer:
    """
    Byte Pair Encoding tokenizer implemented from scratch.
    Follows the original Sennrich et al. (2015) algorithm.
    """

    def __init__(self, vocab_size: int = 500):
        self.vocab_size   = vocab_size
        self.merges: List[Tuple[str, str]] = []   # Ordered list of merge rules
        self.vocab: Dict[str, int] = {}            # token → id
        self.vocab_inv: Dict[int, str] = {}        # id → token

    # ─────────────────────────────────────────────────────────────────────
    # Phase 1: LEARNING — run on training corpus
    # ─────────────────────────────────────────────────────────────────────

    def _get_word_freqs(self, corpus: List[str]) -> Dict[str, int]:
        """
        Convert corpus to word frequency dictionary.
        Each word is represented as a tuple of characters with </w> end marker.
        </w> marks word boundaries — critical for correct segmentation.

        "low" → ('l', 'o', 'w', '</w>')
        """
        word_freqs = Counter()
        for text in corpus:
            words = text.lower().split()
            for word in words:
                # Add end-of-word marker
                word_chars = tuple(list(word) + ['</w>'])
                word_freqs[word_chars] += 1
        return dict(word_freqs)

    def _get_pair_freqs(self, word_freqs: Dict[tuple, int]) -> Counter:
        """
        Count frequency of all adjacent symbol pairs across all words.
        """
        pairs = Counter()
        for word, freq in word_freqs.items():
            for i in range(len(word) - 1):
                pairs[(word[i], word[i+1])] += freq
        return pairs

    def _merge_pair(self, pair: Tuple[str, str],
                    word_freqs: Dict[tuple, int]) -> Dict[tuple, int]:
        """
        Apply one merge: replace all occurrences of `pair` with the merged token.
        """
        new_word_freqs = {}
        bigram = ' '.join(pair)
        replacement = ''.join(pair)
        pattern = re.compile(r'(?<!\S)' + re.escape(bigram) + r'(?!\S)')

        for word, freq in word_freqs.items():
            # Convert tuple to string for regex substitution
            word_str = ' '.join(word)
            merged_str = pattern.sub(replacement, word_str)
            new_word = tuple(merged_str.split())
            new_word_freqs[new_word] = freq

        return new_word_freqs

    def train(self, corpus: List[str]) -> None:
        """
        Run BPE training on a corpus.
        Learns `vocab_size` - |base_chars| merges.
        """
        # Initialize word frequencies
        word_freqs = self._get_word_freqs(corpus)

        # Initialize vocabulary with all unique characters (+ </w>)
        base_vocab = set()
        for word in word_freqs:
            base_vocab.update(word)
        self.vocab = {tok: i for i, tok in enumerate(sorted(base_vocab))}

        print(f"Initial vocab size: {len(self.vocab)} characters")
        print(f"Target vocab size:  {self.vocab_size}")
        print(f"Merges to learn:    {self.vocab_size - len(self.vocab)}")
        print("\nLearning merges...")

        # BPE merge loop
        while len(self.vocab) < self.vocab_size:
            # Find most frequent adjacent pair
            pair_freqs = self._get_pair_freqs(word_freqs)
            if not pair_freqs:
                break

            best_pair = max(pair_freqs, key=pair_freqs.get)
            best_freq = pair_freqs[best_pair]

            if best_freq < 2:
                print(f"  Stopping: best pair frequency = {best_freq} (< 2)")
                break

            # Merge the pair
            new_token = ''.join(best_pair)
            self.merges.append(best_pair)
            self.vocab[new_token] = len(self.vocab)

            # Apply merge to all words
            word_freqs = self._merge_pair(best_pair, word_freqs)

            if len(self.vocab) % 50 == 0:
                print(f"  Vocab size: {len(self.vocab)}, "
                      f"Last merge: {best_pair} → '{new_token}' (freq={best_freq})")

        # Build inverse mapping
        self.vocab_inv = {v: k for k, v in self.vocab.items()}
        print(f"\nFinal vocab size: {len(self.vocab)}")
        print(f"Merge rules learned: {len(self.merges)}")

    # ─────────────────────────────────────────────────────────────────────
    # Phase 2: SEGMENTATION — run on any text
    # ─────────────────────────────────────────────────────────────────────

    def _segment_word(self, word: str) -> List[str]:
        """
        Segment a single word using learned merge rules.
        Apply merges in the same order they were learned (greedy, deterministic).
        """
        # Start with character sequence + end marker
        tokens = list(word) + ['</w>']

        # Apply each merge rule in order
        for merge_left, merge_right in self.merges:
            i = 0
            while i < len(tokens) - 1:
                if tokens[i] == merge_left and tokens[i+1] == merge_right:
                    tokens = tokens[:i] + [''.join([merge_left, merge_right])] + tokens[i+2:]
                else:
                    i += 1

        return tokens

    def tokenize(self, text: str) -> List[str]:
        """Tokenize full text."""
        result = []
        for word in text.lower().split():
            segments = self._segment_word(word)
            # Convert </w> segments: 'low</w>' → 'low'
            clean = [s.replace('</w>', '') for s in segments if s != '</w>']
            result.extend(clean)
        return result

    def encode(self, text: str) -> List[int]:
        tokens = self.tokenize(text)
        return [self.vocab.get(t, self.vocab.get('[UNK]', 0)) for t in tokens]


# ─── Training demonstration ────────────────────────────────────────────

    "low lower lowest",
    "new newer newest",
    "wide wider widest",
    "low low low low",
    "new new newer",
] * 10

bpe.train(corpus)

    tokens = bpe.tokenize(word)
    print(f"  '{word}' → {tokens}")
```

```python
# Classic BPE example from Sennrich et al. (2015)
# Corpus: {"low": 5, "lower": 2, "newest": 6, "wider": 3}

print("""
Initial representation (with </w> end marker):
  l o w </w>        (freq: 5)
  l o w e r </w>    (freq: 2)
  n e w e s t </w>  (freq: 6)
  w i d e r </w>    (freq: 3)

Step 1: Count all adjacent pairs
  (e, s) appears:   6 (in "newest")
  (e, r) appears:   2+3 = 5
  (e, w) appears:   6 (in "newest")
  ... etc.
  Most frequent: (e, s) with count 6

  Merge: (e, s) → "es"
  n e w es t </w>   ← "newest" becomes ["n","e","w","es","t","</w>"]

Step 2: Count again...
  (es, t) appears:  6 (only in "newest")
  Most frequent: (es, t) with count 6

  Merge: (es, t) → "est"
  n e w est </w>

Step 3: Continue...
  Merge: (est, </w>) → "est</w>"  → "est" at word end
  ...
  Eventually: "newest" → ["new", "est"]
              "lower"  → ["low", "er"]

Final vocabulary adds:
  "es", "est", "est</w>", "est<w>", "low", "er", ...
""")
```

---

### 🆚 BPE vs. WordPiece — The Key Difference

```
BPE:       Merge the pair with HIGHEST RAW FREQUENCY
WordPiece: Merge the pair that MAXIMIZES LANGUAGE MODEL LIKELIHOOD

BPE picks:  argmax freq(a, b)

WordPiece picks: argmax freq(a, b) / (freq(a) × freq(b))
                 ≈ argmax P(ab) / (P(a) × P(b))
                 ≈ mutual information between a and b

Intuition:
  BPE merges "e" + "s" because they appear together often (e.g., "goes", "makes", "likes")
  WordPiece asks: Does "es" appear MORE than chance would predict?
  If P(e)=0.10 and P(s)=0.05, chance predicts P(es)=0.005
  If actual P(es)=0.020, that's 4× more than chance → strong candidate to merge
```

---

### 💻 WordPiece from Scratch

```python
from collections import Counter, defaultdict
from typing import Dict, List, Tuple, Optional
import math

class WordPieceTokenizer:
    """
    WordPiece tokenizer as used in BERT (Devlin et al., 2018).
    Key features:
      - ## prefix for continuation tokens (non-initial subwords)
      - Maximizes language model likelihood for merge selection
      - Falls back to character-level for unknown characters
    """

    def __init__(self, vocab_size: int = 1000, unk_token: str = '[UNK]'):
        self.vocab_size = vocab_size
        self.unk_token  = unk_token
        self.vocab: Dict[str, int] = {}
        self.vocab_inv: Dict[int, str] = {}
        self.merges: List[Tuple[str, str]] = []

    # ─────────────────────────────────────────────────────────────────────
    # Training
    # ─────────────────────────────────────────────────────────────────────

    def _initialize_vocab(self, word_freqs: Counter) -> dict:
        """
        Initialize with character-level vocabulary.
        IMPORTANT: WordPiece uses ## prefix for non-initial chars!

        "hello" → ['h', '##e', '##l', '##l', '##o']
          'h'   = word-initial character (no prefix)
          '##e' = continuation character (## prefix)
        """
        char_freqs = defaultdict(int)
        word_sequences = {}

        for word, freq in word_freqs.items():
            chars = []
            for i, ch in enumerate(word):
                if i == 0:
                    chars.append(ch)          # No prefix for first char
                    char_freqs[ch] += freq
                else:
                    chars.append(f'##{ch}')   # ## prefix for rest
                    char_freqs[f'##{ch}'] += freq
            word_sequences[word] = (chars, freq)

        return word_sequences, char_freqs

    def _compute_pair_scores(self, word_sequences: dict, token_freqs: dict) -> dict:
        """
        Compute WordPiece score for each adjacent pair:
          score(a, b) = freq(ab) / (freq(a) × freq(b))

        This favors pairs where the combination is
        more likely than random co-occurrence.
        """
        pair_freqs = Counter()
        for word, (tokens, freq) in word_sequences.items():
            for i in range(len(tokens) - 1):
                pair_freqs[(tokens[i], tokens[i+1])] += freq

        scores = {}
        for (a, b), ab_freq in pair_freqs.items():
            freq_a = token_freqs.get(a, 1)
            freq_b = token_freqs.get(b, 1)
            scores[(a, b)] = ab_freq / (freq_a * freq_b)

        return scores, pair_freqs

    def _merge_pair(self, pair: Tuple[str, str], word_sequences: dict,
                    token_freqs: dict) -> Tuple[dict, dict]:
        """Apply merge and update frequencies."""
        a, b     = pair
        new_tok  = a + b.replace('##', '')   # 'low' + '##e' → 'lowe'
        new_seqs = {}
        token_freqs = dict(token_freqs)
        token_freqs[new_tok] = 0

        for word, (tokens, freq) in word_sequences.items():
            new_tokens = []
            i = 0
            merged = False
            while i < len(tokens):
                if i < len(tokens) - 1 and tokens[i] == a and tokens[i+1] == b:
                    new_tokens.append(new_tok)
                    token_freqs[new_tok] += freq
                    token_freqs[a] = max(0, token_freqs.get(a, 0) - freq)
                    token_freqs[b] = max(0, token_freqs.get(b, 0) - freq)
                    i += 2
                    merged = True
                else:
                    new_tokens.append(tokens[i])
                    i += 1
            new_seqs[word] = (new_tokens, freq)

        return new_seqs, token_freqs

    def train(self, corpus: List[str], verbose: bool = True) -> None:
        """Run WordPiece training."""
        # Count word frequencies
        word_freqs = Counter()
        for text in corpus:
            word_freqs.update(text.lower().split())

        # Initialize
        word_sequences, token_freqs = self._initialize_vocab(word_freqs)

        # Base vocabulary: special tokens + all characters
        special_tokens = ['[PAD]', '[UNK]', '[CLS]', '[SEP]', '[MASK]']
        self.vocab = {tok: i for i, tok in enumerate(special_tokens)}
        for tok in sorted(token_freqs.keys()):
            if tok not in self.vocab:
                self.vocab[tok] = len(self.vocab)

        if verbose:
            print(f"Initial vocab:  {len(self.vocab)} characters")
            print(f"Target vocab:   {self.vocab_size}")

        # WordPiece merge loop
        iteration = 0
        while len(self.vocab) < self.vocab_size:
            scores, pair_freqs = self._compute_pair_scores(word_sequences, token_freqs)
            if not scores:
                break

            # Pick pair with HIGHEST score (mutual information)
            best_pair  = max(scores, key=scores.get)
            best_score = scores[best_pair]
            best_freq  = pair_freqs[best_pair]

            if best_freq < 2:
                break

            # Merge
            a, b = best_pair
            new_tok = a + b.replace('##', '')
            self.merges.append(best_pair)
            self.vocab[new_tok] = len(self.vocab)

            word_sequences, token_freqs = self._merge_pair(
                best_pair, word_sequences, token_freqs
            )

            iteration += 1
            if verbose and iteration <= 10:
                print(f"  Iter {iteration:2d}: merge ('{a}', '{b}') → '{new_tok}' "
                      f"[score={best_score:.4f}, freq={best_freq}]")

        self.vocab_inv = {v: k for k, v in self.vocab.items()}
        if verbose:
            print(f"\nFinal vocab size: {len(self.vocab)}")

    # ─────────────────────────────────────────────────────────────────────
    # Segmentation: Longest Match First (Greedy)
    # ─────────────────────────────────────────────────────────────────────

    def _tokenize_word(self, word: str) -> List[str]:
        """
        Segment a word using longest-match-first (greedy) strategy.
        This is the standard BERT WordPiece segmentation.
        """
        if word in self.vocab:
            return [word]

        tokens = []
        start  = 0

        while start < len(word):
            end   = len(word)
            found = False

            # Try longest possible substring first
            while start < end:
                substr = word[start:end]
                candidate = substr if start == 0 else f'##{substr}'

                if candidate in self.vocab:
                    tokens.append(candidate)
                    start = end
                    found = True
                    break
                end -= 1

            if not found:
                return [self.unk_token]   # Cannot segment → [UNK]

        return tokens

    def tokenize(self, text: str) -> List[str]:
        result = []
        for word in text.lower().split():
            result.extend(self._tokenize_word(word))
        return result

    def encode(self, text: str) -> List[int]:
        tokens = self.tokenize(text)
        return [self.vocab.get(t, self.vocab.get(self.unk_token, 0)) for t in tokens]

    def decode(self, ids: List[int]) -> str:
        tokens = [self.vocab_inv.get(i, '[UNK]') for i in ids]
        # Reconstruct: remove ## and join
        text = ''
        for tok in tokens:
            if tok.startswith('##'):
                text += tok[2:]   # Continuation: no space
            elif tok in {'[PAD]', '[CLS]', '[SEP]', '[MASK]', '[UNK]'}:
                continue
            else:
                text += (' ' if text else '') + tok   # New word: add space
        return text.strip()


# ── Training and demonstration ─────────────────────────────────────────
corpus = [
    "the cat sat on the mat",
    "the cat is on the mat too",
    "low lower lowest",
    "new newer newest",
    "where is the cat sitting",
] * 50

wp = WordPieceTokenizer(vocab_size=80)
wp.train(corpus, verbose=True)

print("\n── WordPiece Tokenization ──")
for word in ['cat', 'cats', 'sitting', 'lower', 'lowest', 'newest', 'unknown']:
    tokens = wp.tokenize(word)
    print(f"  '{word}' → {tokens}")

print("\n── Encode/Decode round-trip ──")
text = "the cat is sitting on the mat"
ids = wp.encode(text)
decoded = wp.decode(ids)
print(f"Original: '{text}'")
print(f"Encoded:  {ids}")
print(f"Decoded:  '{decoded}'")
```

| Aspect | BPE | WordPiece |
|---|---|---|
| Merge criterion | Max raw frequency | Max likelihood (mutual info) |
| Result | Frequency-biased | Statistically principled |
| Continuation prefix | None (Ġ for space) | `##` for continuations |
| End-of-word marker | `Ġ` prefix on next word | None |
| OOV handling | Byte fallback (GPT-2) | [UNK] or char fallback |
| Training speed | Faster | Slightly slower |
| Models | GPT-2, RoBERTa, Falcon | BERT, DistilBERT, ALBERT |

### 🌐 What is SentencePiece?

SentencePiece (Kudo & Richardson, 2018) is a **tokenization framework** (not an algorithm) that:
1. Treats text as a **raw byte/character stream** — no pre-tokenization or whitespace splitting
2. Marks spaces with **`▁` (U+2581)** — space is part of the token
3. Supports **BPE or Unigram LM** as the underlying algorithm
4. Is **language-agnostic** — works for Japanese, Chinese, Thai (no spaces!) equally well

```
Standard BPE/WordPiece:    "Hello world" → pre-split → ["hello", "world"] → merge
SentencePiece:             "Hello world" → treat as stream → "▁Hello▁world" → segment
                           → ["▁Hello", "▁world"]  or ["▁Hel", "lo", "▁wor", "ld"]

Key difference:
  Standard: space is CONSUMED during pre-tokenization
  SentencePiece: space is ENCODED as ▁ — fully reversible!
```

---

### 📐 Unigram Language Model Algorithm

The **Unigram LM** (Kudo, 2018) takes a top-down approach (unlike BPE's bottom-up):

```
BPE (bottom-up):
  Start with characters → iteratively MERGE most frequent pair → build up tokens

Unigram LM (top-down):
  Start with large candidate vocabulary (all substrings) → iteratively PRUNE
  tokens that minimally hurt the corpus log-likelihood

Algorithm:
  1. Initialize: Take all substrings of the corpus as candidates (~20× target vocab)
  2. E-step: For each word, compute the best segmentation using Viterbi algorithm
  3. M-step: Remove X% of tokens with smallest individual contribution to likelihood
  4. Repeat until |vocab| = target size

Score of a segmentation x = (x₁, x₂, ..., xₙ):
  P(x) = ∏ P(xᵢ)    where P(xᵢ) is the unigram probability of token xᵢ
  Best segmentation: argmax log P(x₁,...,xₙ)
```

### 🔍 Unigram LM's Key Advantage: Multiple Valid Segmentations

```python
# BPE: DETERMINISTIC — one and only one segmentation
# Unigram LM: PROBABILISTIC — can sample from all valid segmentations!

# Example: "running"
# Unigram can segment as:
#   - ["running"]        P = 0.01
#   - ["run", "##ning"]  P = 0.05
#   - ["runn", "##ing"]  P = 0.03
#   - ["r", "##u", "##n", "##n", "##i", "##n", "##g"]  P = 0.0001

# At inference: use best (MAP) segmentation
# During training: sample from distribution! (regularization effect)

# SentencePiece supports this with:
sp = spm.SentencePieceProcessor()
sp.load('/tmp/sp_unigram.model')

text = "natural language processing"
print("Deterministic segmentation:")
print(f"  {sp.encode(text, out_type=str)}")

print("\nSampled segmentations (alpha=0.1, nbest_size=-1):")
for i in range(5):
    sampled = sp.sample_encode(text, nbest_size=-1, alpha=0.1, out_type=str)
    print(f"  Sample {i+1}: {sampled}")
# Each call may return a different valid segmentation!
# This acts as data augmentation during training
```

## ⚠️ Top 7 Tokenization Pitfalls

1. **Mixing tokenizers** — never use BERT's tokenizer with GPT weights. They're inseparable.
2. **Off-by-one in special tokens** — always check if `[CLS]` and `[SEP]` are included in your `input_ids`.
3. **Truncation removes context silently** — always set `truncation=True` intentionally, never by accident.
4. **Decoding ##tokens naively** — joining `['token', '##ization']` as `"token ization"` is wrong. Remove `##`, no space.
5. **Language mismatch** — `bert-base-uncased` has very poor coverage of non-Latin scripts. Use `bert-base-multilingual-cased` or XLM-R.
6. **Token = word assumption** — 1 token ≠ 1 word. NEVER count tokens and call them "words".
7. **Fertility blindness** — always measure average tokens/word for your domain. Highly technical text can have 2–3x higher fertility than general English.
