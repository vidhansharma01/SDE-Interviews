## Day 1 — Embeddings: From Discrete to Continuous Space

### 🎯 Learning Objectives
- Understand **why** discrete tokens cannot be fed directly to a neural network
- Build an embedding layer from scratch
- See how embeddings capture semantic meaning geometrically

---

### 🧩 The Problem: Discrete Symbols

Words, characters, and tokens are **discrete symbols** — they have no inherent numerical relationship. The word "cat" and the word "dog" are equally distant from "automobile" if we use one-hot encoding.

```python
# One-hot encoding — the naive approach
vocab = {"cat": 0, "dog": 1, "fish": 2, "car": 3}
vocab_size = len(vocab)

def one_hot(word, vocab):
    v = [0] * len(vocab)
    v[vocab[word]] = 1
    return v

print(one_hot("cat",  vocab))  # [1, 0, 0, 0]
print(one_hot("dog",  vocab))  # [0, 1, 0, 0]
print(one_hot("fish", vocab))  # [0, 0, 1, 0]

# Problems with one-hot:
# 1. Dimensionality = vocab_size (can be 50,000+)
# 2. All words are equidistant — no semantic similarity
# 3. Completely sparse — 99.99% zeros
# 4. No concept of "cat" and "dog" being more similar than "cat" and "car"
```

---

### 🧠 The Solution: Dense Embedding Vectors

An **embedding** maps each discrete token to a **dense, low-dimensional vector** where:
- Similar tokens are **geometrically close**
- Relationships are encoded as **directions** in vector space
- The vectors are **learned** during training

```
Discrete space:               Continuous embedding space (2D simplified):
                              ┌──────────────────────────────────────┐
"cat"  → [1, 0, 0, 0]        │     cat •          • dog             │
"dog"  → [0, 1, 0, 0]        │              • wolf                  │
"fish" → [0, 0, 1, 0]        │                                      │
"car"  → [0, 0, 0, 1]        │  • fish                              │
                              │                                      │
                              │                        • car         │
                              │                        • truck       │
                              └──────────────────────────────────────┘
```

---

### 📐 Embedding Math

An embedding layer is simply a **lookup table** — a matrix `E` of shape `(vocab_size, embed_dim)`.

```
E ∈ R^(V × d)    where V = vocab_size, d = embedding dimension

For token with index i:
  embedding(i) = E[i]  →  a vector of shape (d,)
```

This is equivalent to a linear transformation of a one-hot vector:
```
embedding(i) = one_hot(i) @ E    ← but we skip the matmul and just index
```

### 💻 Embedding Layer from Scratch

```python
import numpy as np
import torch
import torch.nn as nn

# ── Numpy implementation ──────────────────────────────────────────────
class EmbeddingLayerNumpy:
    def __init__(self, vocab_size: int, embed_dim: int):
        # Initialize with small random values
        self.E = np.random.randn(vocab_size, embed_dim) * 0.01
        print(f"Embedding matrix shape: {self.E.shape}")

    def forward(self, token_indices):
        """token_indices: list/array of integer token IDs"""
        return self.E[token_indices]   # Direct row lookup

vocab_size = 10_000
embed_dim  = 256
embedding  = EmbeddingLayerNumpy(vocab_size, embed_dim)

# A sentence: ["the", "cat", "sat"] → token IDs → embeddings
token_ids   = [4, 9, 102]
embeddings  = embedding.forward(token_ids)
print(f"Input:  {token_ids}")
print(f"Output: shape {embeddings.shape}")  # (3, 256)


# ── PyTorch implementation ────────────────────────────────────────────
class EmbeddingLayerTorch(nn.Module):
    def __init__(self, vocab_size: int, embed_dim: int, padding_idx: int = 0):
        super().__init__()
        # nn.Embedding is essentially a learnable weight matrix
        self.embed = nn.Embedding(
            num_embeddings=vocab_size,
            embedding_dim=embed_dim,
            padding_idx=padding_idx   # index 0 always maps to zero vector
        )

    def forward(self, token_ids: torch.Tensor) -> torch.Tensor:
        """
        Input:  token_ids  shape (batch_size, seq_len)
        Output: embeddings shape (batch_size, seq_len, embed_dim)
        """
        return self.embed(token_ids)

# Test
embed_layer = EmbeddingLayerTorch(vocab_size=10_000, embed_dim=256)

batch = torch.tensor([[4, 9, 102, 7],    # Sentence 1
                       [1, 55, 3, 0]])    # Sentence 2 (0 = padding)

output = embed_layer(batch)
print(f"Input shape:  {batch.shape}")    # (2, 4)
print(f"Output shape: {output.shape}")   # (2, 4, 256)

# Inspect weight matrix
print(f"Weight matrix: {embed_layer.embed.weight.shape}")  # (10000, 256)
```

## Day 2 — The Attention Mechanism

### 🎯 Learning Objectives
- Understand the Query-Key-Value (QKV) formulation

---

### 🧠 The Core Intuition

Attention answers one question: **"When processing this token, how much should I focus on every other token in the sequence?"**

Think of a **search engine**:
- **Query (Q):** What you're searching for → *"I need information about X"*
- **Key (K):**   The index of stored information → *"Here's what I can offer"*
- **Value (V):**  The actual information retrieved → *"Here is the content"*

```
Analogy: Library Search
─────────────────────────────────────────────────────────
Your search query: "machine learning"   → Q (your need)
Book index cards:  "deep learning"      → K₁  matched!
                   "cooking recipes"    → K₂  not matched
                   "neural networks"    → K₃  matched!
Retrieved books:                        → V₁, V₃ (weighted by match strength)
```

---

### 📐 Scaled Dot-Product Attention Formula

```
                  QK^T
Attention(Q,K,V) = softmax(─────) V
                   √d_k

Where:
  Q ∈ R^(seq_len × d_k)   — Queries
  K ∈ R^(seq_len × d_k)   — Keys
  V ∈ R^(seq_len × d_v)   — Values
  d_k = dimension of keys/queries (used for scaling)
```

#### Step-by-step breakdown:

```
Step 1: QK^T → Compute raw similarity scores
         Shape: (seq_len, d_k) × (d_k, seq_len) = (seq_len, seq_len)
         Each entry [i,j] = how much token i "attends to" token j

Step 2: / √d_k → Scale scores down
         Prevents dot products from growing too large in high dimensions
         Large values → softmax becomes too peaky → vanishing gradients

Step 3: softmax() → Normalize to probability distribution
         Each row sums to 1.0 → attention weights per query token

Step 4: × V → Weighted sum of values
         Shape: (seq_len, seq_len) × (seq_len, d_v) = (seq_len, d_v)
         Output: context-aware representation for each token
```

---

### 💻 Attention from Scratch

```python
import torch
import torch.nn.functional as F
import numpy as np
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Args:
        Q:    (batch, seq_q, d_k)
        K:    (batch, seq_k, d_k)
        V:    (batch, seq_k, d_v)
        mask: (batch, seq_q, seq_k) — optional boolean mask

    Returns:
        output:  (batch, seq_q, d_v)
        weights: (batch, seq_q, seq_k)  ← attention weights for visualization
    """
    d_k = Q.shape[-1]

    # Step 1: Raw similarity scores
    scores = Q @ K.transpose(-2, -1)          # (batch, seq_q, seq_k)

    # Step 2: Scale
    scores = scores / math.sqrt(d_k)

    # Step 3: Optional masking (fill masked positions with -inf before softmax)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))

    # Step 4: Softmax → attention weights
    weights = F.softmax(scores, dim=-1)        # Row-wise softmax

    # Step 5: Weighted sum of values
    output = weights @ V                        # (batch, seq_q, d_v)

    return output, weights


# ── Worked Example ────────────────────────────────────────────────────
torch.manual_seed(42)
batch_size = 1
seq_len    = 4
d_k        = 8   # Query/Key dimension
d_v        = 8   # Value dimension

# Random Q, K, V
Q = torch.randn(batch_size, seq_len, d_k)
K = torch.randn(batch_size, seq_len, d_k)
V = torch.randn(batch_size, seq_len, d_v)

output, weights = scaled_dot_product_attention(Q, K, V)

print(f"Q shape:       {Q.shape}")       # (1, 4, 8)
print(f"K shape:       {K.shape}")       # (1, 4, 8)
print(f"V shape:       {V.shape}")       # (1, 4, 8)
print(f"Output shape:  {output.shape}")  # (1, 4, 8)
print(f"Weights shape: {weights.shape}") # (1, 4, 4)
print(f"\nAttention weights (first batch):\n{weights[0].detach().numpy().round(3)}")
# Each row is a probability distribution summing to 1
```

## Day 3 — Self-Attention & Multi-Head Attention

### 🎯 Learning Objectives

- Implement full self-attention with learned weight matrices

---

### 🧠 Self-Attention: Q, K, V from the Same Source

In self-attention, **Q, K, and V all come from the same input sequence**. Each token creates its own query, key, and value via learned projection matrices:

```
Input:   X ∈ R^(seq_len × d_model)

Q = X @ W_Q    W_Q ∈ R^(d_model × d_k)
K = X @ W_K    W_K ∈ R^(d_model × d_k)
V = X @ W_V    W_V ∈ R^(d_model × d_v)
```

**Why project?** The projection matrices are *learned* — they teach the model:
- `W_Q`: "What am I looking for?"
- `W_K`: "What do I advertise as my content?"
- `W_V`: "What do I actually contribute when selected?"

---

### 💻 Single-Head Self-Attention with Learned Projections

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class SingleHeadSelfAttention(nn.Module):
    def __init__(self, d_model: int, d_k: int):
        super().__init__()
        self.d_k    = d_k
        self.W_Q    = nn.Linear(d_model, d_k, bias=False)
        self.W_K    = nn.Linear(d_model, d_k, bias=False)
        self.W_V    = nn.Linear(d_model, d_k, bias=False)
        self.W_out  = nn.Linear(d_k, d_model, bias=False)  # Output projection

    def forward(self, x: torch.Tensor, mask=None):
        """
        x:    (batch, seq_len, d_model)
        mask: (batch, seq_len, seq_len) — optional

        Returns:
            output:  (batch, seq_len, d_model)
            weights: (batch, seq_len, seq_len)
        """
        # ── Project to Q, K, V ─────────────────────────
        Q = self.W_Q(x)    # (batch, seq_len, d_k)
        K = self.W_K(x)    # (batch, seq_len, d_k)
        V = self.W_V(x)    # (batch, seq_len, d_k)

        # ── Scaled dot-product attention ────────────────
        scores  = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        weights = F.softmax(scores, dim=-1)
        context = weights @ V             # (batch, seq_len, d_k)

        # ── Output projection ────────────────────────────
        output  = self.W_out(context)    # (batch, seq_len, d_model)
        return output, weights


# Test
d_model = 64
d_k     = 32
attn    = SingleHeadSelfAttention(d_model, d_k)

x = torch.randn(2, 10, d_model)   # batch=2, seq=10
out, w = attn(x)
print(f"Input:   {x.shape}")    # (2, 10, 64)
print(f"Output:  {out.shape}")  # (2, 10, 64)
print(f"Weights: {w.shape}")    # (2, 10, 10)
```

### 🧠 Why Multi-Head Attention?

A single attention head looks at the sequence from **one perspective**. Multi-Head Attention runs **H parallel attention heads**, each with its own projections — allowing the model to simultaneously attend to:

- **Head 1:** Subject-verb agreement (`"cat"` → `"sat"`)
- **Head 2:** Pronoun resolution (`"it"` → `"cat"`)
- **Head 3:** Syntactic structure (`"on"` → preposition group)
- **Head 4:** Long-range dependencies

```
MHA formula:
  head_i = Attention(X W_Q^i, X W_K^i, X W_V^i)
  MHA(X) = Concat(head_1, ..., head_H) @ W_O

  d_k = d_model / H   ← Each head uses a smaller dimension
```

---

### 💻 Multi-Head Attention from Scratch

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0, "d_model must be divisible by num_heads"

        self.d_model   = d_model
        self.num_heads = num_heads
        self.d_k       = d_model // num_heads   # Dimension per head

        # Combined projections (more efficient than separate)
        self.W_Q = nn.Linear(d_model, d_model, bias=False)
        self.W_K = nn.Linear(d_model, d_model, bias=False)
        self.W_V = nn.Linear(d_model, d_model, bias=False)
        self.W_O = nn.Linear(d_model, d_model, bias=False)   # Output projection

        self.dropout = nn.Dropout(dropout)

    def split_heads(self, x: torch.Tensor) -> torch.Tensor:
        """
        Reshape from (batch, seq, d_model) to (batch, num_heads, seq, d_k)
        """
        batch, seq, _ = x.shape
        x = x.view(batch, seq, self.num_heads, self.d_k)
        return x.transpose(1, 2)    # (batch, num_heads, seq, d_k)

    def forward(self, Q_in, K_in, V_in, mask=None):
        """
        Q_in, K_in, V_in: (batch, seq, d_model)
        For self-attention: Q_in = K_in = V_in = x
        For cross-attention: Q_in ≠ K_in = V_in
        """
        batch = Q_in.shape[0]

        # ── 1. Project all inputs ───────────────────────────────────────
        Q = self.W_Q(Q_in)    # (batch, seq_q, d_model)
        K = self.W_K(K_in)    # (batch, seq_k, d_model)
        V = self.W_V(V_in)    # (batch, seq_k, d_model)

        # ── 2. Split into H heads ────────────────────────────────────────
        Q = self.split_heads(Q)   # (batch, H, seq_q, d_k)
        K = self.split_heads(K)   # (batch, H, seq_k, d_k)
        V = self.split_heads(V)   # (batch, H, seq_k, d_k)

        # ── 3. Scaled dot-product attention (all heads in parallel) ──────
        scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)  # (batch, H, seq_q, seq_k)

        if mask is not None:
            # mask shape: (batch, 1, seq_q, seq_k) — broadcast across heads
            scores = scores.masked_fill(mask == 0, float('-inf'))

        weights = F.softmax(scores, dim=-1)           # (batch, H, seq_q, seq_k)
        weights = self.dropout(weights)
        context = weights @ V                          # (batch, H, seq_q, d_k)

        # ── 4. Concatenate heads ─────────────────────────────────────────
        context = context.transpose(1, 2).contiguous()           # (batch, seq_q, H, d_k)
        context = context.view(batch, -1, self.d_model)          # (batch, seq_q, d_model)

        # ── 5. Final output projection ────────────────────────────────────
        output = self.W_O(context)     # (batch, seq_q, d_model)
        return output, weights


# Test
mha = MultiHeadAttention(d_model=512, num_heads=8)
x   = torch.randn(2, 20, 512)   # batch=2, seq=20, d=512

out, weights = mha(x, x, x)
print(f"Input:   {x.shape}")        # (2, 20, 512)
print(f"Output:  {out.shape}")      # (2, 20, 512)
print(f"Weights: {weights.shape}")  # (2, 8, 20, 20)  — 8 heads!

# Count parameters
total_params = sum(p.numel() for p in mha.parameters())
print(f"Parameters: {total_params:,}")   # 4 × (512×512) = 1,048,576
```

### 🎭 Part A — Masked Multi-Head Attention

#### Why Masking?

During **language model training** (predicting the next word), each position must only see **past and present** tokens — never future ones.

```
Sentence: "The cat sat on the mat"
          ─────────────────────────────────────────────
Token 0:  "The"    — can see:  [The]
Token 1:  "cat"    — can see:  [The, cat]
Token 2:  "sat"    — can see:  [The, cat, sat]
Token 3:  "on"     — can see:  [The, cat, sat, on]
...

Without masking, "sat" could cheat by seeing "on", "the", "mat" → not true generation!
```

The mask is a **lower-triangular matrix** of ones (allow) and zeros (block):

```
Causal mask for seq_len=4:
     The  cat  sat  on
The [  1    0    0   0 ]   ← "The" only attends to itself
cat [  1    1    0   0 ]   ← "cat" attends to [The, cat]
sat [  1    1    1   0 ]
on  [  1    1    1   1 ]
```

---

### 💻 Masked Attention Implementation

```python
def make_causal_mask(seq_len: int, device='cpu') -> torch.Tensor:
    """
    Creates a causal (lower-triangular) attention mask.
    Returns: (1, 1, seq_len, seq_len)  — broadcastable across batch and heads
    """
    # torch.tril fills upper triangle with zeros
    mask = torch.tril(torch.ones(seq_len, seq_len, device=device))
    return mask.unsqueeze(0).unsqueeze(0)   # (1, 1, seq_len, seq_len)
```

### 📍 Part B — Positional Encoding

#### Why Transformers Need Position Information

Attention is **permutation-invariant** — if you shuffle the input tokens, the output is the same (just shuffled). Transformers have **no built-in sense of order!**

```python
# Demonstration: attention doesn't care about order
x1 = torch.tensor([[[1.,0.],[0.,1.],[0.,0.]]])   # tokens: A, B, C
x2 = torch.tensor([[[0.,1.],[1.,0.],[0.,0.]]])   # tokens: B, A, C (shuffled)

# Without positional encoding, the model treats these identically
# We must inject position information separately
```

#### Sinusoidal Positional Encoding (Original Transformer)

```python
class SinusoidalPositionalEncoding(nn.Module):
    """
    Fixed sinusoidal positional encoding from 'Attention Is All You Need' (2017).

    PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
    PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

    Properties:
    - Unique encoding for each position
    - Relative positions have consistent patterns
    - Works for sequences longer than seen during training
    - NOT learned — fixed formula
    """
    def __init__(self, d_model: int, max_seq_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

        # Pre-compute PE matrix: (max_seq_len, d_model)
        pe = torch.zeros(max_seq_len, d_model)

        position  = torch.arange(0, max_seq_len).unsqueeze(1).float()   # (max_seq_len, 1)
        div_term  = torch.exp(
            torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model)
        )                                                                  # (d_model/2,)

        pe[:, 0::2] = torch.sin(position * div_term)   # Even dimensions → sin
        pe[:, 1::2] = torch.cos(position * div_term)   # Odd dimensions  → cos

        pe = pe.unsqueeze(0)                            # (1, max_seq_len, d_model)
        self.register_buffer('pe', pe)                  # Not a parameter — just a buffer

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: (batch, seq_len, d_model)
        Returns: x + PE[:, :seq_len, :]
        """
        x = x + self.pe[:, :x.shape[1], :]
        return self.dropout(x)
```

#### Learned Positional Encoding (BERT, GPT-2 style)

```python
class LearnedPositionalEncoding(nn.Module):
    """
    Learned positional encoding — each position has its own trainable vector.
    Used by: BERT, GPT-2, RoBERTa
    Limitation: fixed to max_seq_len seen during training
    """
    def __init__(self, d_model: int, max_seq_len: int = 512, dropout: float = 0.1):
        super().__init__()
        self.pos_embedding = nn.Embedding(max_seq_len, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        seq_len   = x.shape[1]
        positions = torch.arange(seq_len, device=x.device)  # [0, 1, 2, ..., seq_len-1]
        x = x + self.pos_embedding(positions)               # Broadcast across batch
        return self.dropout(x)
```

#### Rotary Positional Encoding — RoPE (LLaMA, GPT-NeoX)

```python
# RoPE encodes relative positions by ROTATING query/key vectors
# instead of adding a fixed vector to embeddings.
#
# Key advantages:
# - Encodes RELATIVE position (token i relative to token j)
# - Extrapolates beyond training context length
# - Used by: LLaMA, Falcon, Mistral, Gemma
#
# Math: rotate Q and K by angle proportional to position before dot product
# Attention(Q, K) captures relative positions naturally through rotation

def rotate_half(x):
    x1, x2 = x.chunk(2, dim=-1)
    return torch.cat([-x2, x1], dim=-1)

def apply_rope(x, cos, sin):
    return x * cos + rotate_half(x) * sin
```

#### PE Comparison Table
| Method | Learned | Extrapolates | Used By |
|---|---|---|---|
| Sinusoidal | No (fixed) | Yes | Original Transformer |
| Learned | Yes | No (fixed max) | BERT, GPT-2 |
| ALiBi | No | Yes | BLOOM, MPT |
| RoPE | Partially | Yes | LLaMA, Mistral, Gemma |
| NoPE | — | — | Some modern LLMs experiment without PE |

### 💻 Encoder Block

```python
class FeedForwardNetwork(nn.Module):
    """
    Position-wise Feed-Forward Network.
    Applied independently to each position: FFN(x) = max(0, xW₁+b₁)W₂+b₂
    """
    def __init__(self, d_model: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),           # Original uses ReLU; GELU used in BERT/GPT
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )

    def forward(self, x):
        return self.net(x)


class EncoderBlock(nn.Module):
    """
    Single Transformer Encoder block:
    x → Self-Attention → Add & Norm → FFN → Add & Norm
    """
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn       = FeedForwardNetwork(d_model, d_ff, dropout)
        self.norm1     = nn.LayerNorm(d_model)
        self.norm2     = nn.LayerNorm(d_model)
        self.dropout   = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor, src_mask=None):
        """
        x:        (batch, seq_len, d_model)
        src_mask: padding mask to ignore PAD tokens
        """
        # ── Sublayer 1: Self-Attention with Pre-Norm ─────────
        x_norm = self.norm1(x)
        attn_out, _ = self.self_attn(x_norm, x_norm, x_norm, mask=src_mask)
        x = x + self.dropout(attn_out)   # Residual connection

        # ── Sublayer 2: Feed-Forward with Pre-Norm ───────────
        x_norm = self.norm2(x)
        ffn_out = self.ffn(x_norm)
        x = x + self.dropout(ffn_out)    # Residual connection

        return x


class TransformerEncoder(nn.Module):
    def __init__(self, vocab_size, d_model, num_heads, d_ff, num_layers,
                 max_seq_len=512, dropout=0.1):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, d_model, padding_idx=0)
        self.pos_encoding    = SinusoidalPositionalEncoding(d_model, max_seq_len, dropout)
        self.layers          = nn.ModuleList([
            EncoderBlock(d_model, num_heads, d_ff, dropout)
            for _ in range(num_layers)
        ])
        self.norm = nn.LayerNorm(d_model)

    def forward(self, src: torch.Tensor, src_mask=None):
        """
        src: (batch, src_seq_len) — token IDs
        Returns: (batch, src_seq_len, d_model)
        """
        x = self.token_embedding(src)   # (batch, seq, d_model)
        x = self.pos_encoding(x)

        for layer in self.layers:
            x = layer(x, src_mask)

        return self.norm(x)             # Final layer norm
```

### 💻 Decoder Block

```python
class DecoderBlock(nn.Module):
    """
    Single Transformer Decoder block:
    x → Masked Self-Attention → Add & Norm
      → Cross-Attention (with encoder) → Add & Norm
      → FFN → Add & Norm
    """
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.masked_self_attn = MultiHeadAttention(d_model, num_heads, dropout)  # Masked
        self.cross_attn       = MultiHeadAttention(d_model, num_heads, dropout)  # Cross-attention
        self.ffn              = FeedForwardNetwork(d_model, d_ff, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, encoder_out, tgt_mask=None, src_mask=None):
        """
        x:           (batch, tgt_seq_len, d_model)   — decoder input
        encoder_out: (batch, src_seq_len, d_model)   — encoder output
        tgt_mask:    causal mask for decoder self-attention
        src_mask:    padding mask for encoder output
        """
        # ── Sublayer 1: Masked Self-Attention ────────────────────────────
        x_norm = self.norm1(x)
        masked_out, _ = self.masked_self_attn(x_norm, x_norm, x_norm, mask=tgt_mask)
        x = x + self.dropout(masked_out)

        # ── Sublayer 2: Cross-Attention ───────────────────────────────────
        # Q comes from decoder; K, V come from encoder output
        x_norm = self.norm2(x)
        cross_out, cross_weights = self.cross_attn(
            Q_in=x_norm,            # Decoder asks the question
            K_in=encoder_out,       # Encoder provides the index
            V_in=encoder_out,       # Encoder provides the values
            mask=src_mask
        )
        x = x + self.dropout(cross_out)

        # ── Sublayer 3: Feed-Forward ─────────────────────────────────────
        x_norm = self.norm3(x)
        x = x + self.dropout(self.ffn(x_norm))

        return x, cross_weights    # Return cross-weights for visualization


class TransformerEncoderDecoder(nn.Module):
    """Full Encoder-Decoder Transformer for seq2seq tasks (translation, summarization)."""

    def __init__(self, src_vocab_size, tgt_vocab_size, d_model=512, num_heads=8,
                 d_ff=2048, num_encoder_layers=6, num_decoder_layers=6, dropout=0.1):
        super().__init__()
        self.encoder = TransformerEncoder(src_vocab_size, d_model, num_heads,
                                          d_ff, num_encoder_layers, dropout=dropout)
        self.tgt_embedding = nn.Embedding(tgt_vocab_size, d_model, padding_idx=0)
        self.tgt_pos_enc   = SinusoidalPositionalEncoding(d_model, dropout=dropout)
        self.decoder_layers = nn.ModuleList([
            DecoderBlock(d_model, num_heads, d_ff, dropout)
            for _ in range(num_decoder_layers)
        ])
        self.norm       = nn.LayerNorm(d_model)
        self.output_proj = nn.Linear(d_model, tgt_vocab_size)

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        # Encode source
        encoder_out = self.encoder(src, src_mask)       # (batch, src_len, d_model)

        # Prepare target embeddings
        x = self.tgt_embedding(tgt)
        x = self.tgt_pos_enc(x)

        # Decode
        for layer in self.decoder_layers:
            x, _ = layer(x, encoder_out, tgt_mask, src_mask)

        x = self.norm(x)
        logits = self.output_proj(x)                    # (batch, tgt_len, tgt_vocab_size)
        return logits


# Test full encoder-decoder
model = TransformerEncoderDecoder(
    src_vocab_size=32000, tgt_vocab_size=32000,
    d_model=512, num_heads=8, d_ff=2048,
    num_encoder_layers=6, num_decoder_layers=6
)

src = torch.randint(1, 32000, (2, 20))   # 2 source sentences, length 20
tgt = torch.randint(1, 32000, (2, 15))   # 2 target sentences, length 15
tgt_mask = make_causal_mask(15)

print(f"Output logits: {logits.shape}")  # (2, 15, 32000)

print(f"Total parameters: {total_params/1e6:.1f}M")  # ~68M
```

```python
# Instead of [CLS], use the LAST token's hidden state
class GPTForClassification(nn.Module):
    """Use last non-padding token for classification."""
    def __init__(self, gpt_model, num_classes, d_model=768):
        super().__init__()
        self.gpt = gpt_model
        self.classifier = nn.Linear(d_model, num_classes)

    def forward(self, input_ids, attention_mask=None):
        outputs = self.gpt(input_ids, attention_mask=attention_mask)
        hidden  = outputs.last_hidden_state         # (batch, seq, d_model)
        last_h  = hidden[:, -1, :]                  # Last token representation
        return self.classifier(last_h)
```

### 🔗 Cross-Attention: The Bridge Between Sequences

Cross-attention is **attention between two different sequences**. The decoder *queries* the encoder:

```
Decoder token: "I"     → generates Q ("What do I need from the source?")
                                      ↓
Encoder outputs: ["Je", "suis", "étudiant"]  → provide K, V ("Here's what we have")
                                      ↓
Attention weights: Je=0.70, suis=0.20, étudiant=0.10
                                      ↓
Context vector: 0.70 × V_Je + 0.20 × V_suis + 0.10 × V_étudiant
                                      ↓
Decoder uses context to generate "I"
```

**Key formula:**
```
Q  =  decoder_hidden @ W_Q           ← From decoder
K  =  encoder_output @ W_K           ← From encoder
V  =  encoder_output @ W_V           ← From encoder

Cross-Attention(Q, K, V)
```

### 💻 Cross-Attention — Detailed Implementation

```python
class CrossAttention(nn.Module):
    """
    Cross-attention: Decoder queries Encoder memory.
    Q comes from decoder; K, V come from encoder.
    No causal mask — decoder can attend to ANY encoder position.
    """
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model   = d_model
        self.num_heads = num_heads
        self.d_k       = d_model // num_heads

        # Separate projections for Q, K, V
        self.W_Q = nn.Linear(d_model, d_model, bias=False)  # Q from decoder
        self.W_K = nn.Linear(d_model, d_model, bias=False)  # K from encoder
        self.W_V = nn.Linear(d_model, d_model, bias=False)  # V from encoder
        self.W_O = nn.Linear(d_model, d_model, bias=False)
        self.dropout = nn.Dropout(dropout)

    def forward(self, decoder_hidden, encoder_output, encoder_mask=None):
        """
        decoder_hidden:  (batch, tgt_seq, d_model)   ← Q source
        encoder_output:  (batch, src_seq, d_model)   ← K, V source
        encoder_mask:    (batch, 1, 1, src_seq) — mask for padding

        Returns:
            output:   (batch, tgt_seq, d_model)
            weights:  (batch, num_heads, tgt_seq, src_seq)  ← alignment matrix!
        """
        batch, tgt_seq, _ = decoder_hidden.shape
        src_seq = encoder_output.shape[1]

        # ── Project ────────────────────────────────────────────────────
        Q = self.W_Q(decoder_hidden)     # (batch, tgt_seq, d_model)
        K = self.W_K(encoder_output)     # (batch, src_seq, d_model)
        V = self.W_V(encoder_output)     # (batch, src_seq, d_model)

        # ── Split into heads ───────────────────────────────────────────
        def split(t, n):
            b, s, _ = t.shape
            return t.view(b, s, n, -1).transpose(1, 2)   # (batch, heads, seq, d_k)

        Q = split(Q, self.num_heads)   # (batch, H, tgt_seq, d_k)
        K = split(K, self.num_heads)   # (batch, H, src_seq, d_k)
        V = split(V, self.num_heads)   # (batch, H, src_seq, d_k)

        # ── Attention ──────────────────────────────────────────────────
        scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)
        # scores: (batch, H, tgt_seq, src_seq) ← alignment between source and target!

        if encoder_mask is not None:
            scores = scores.masked_fill(encoder_mask == 0, float('-inf'))

        weights = F.softmax(scores, dim=-1)       # (batch, H, tgt_seq, src_seq)
        weights = self.dropout(weights)
        context = weights @ V                      # (batch, H, tgt_seq, d_k)

        # ── Concat and project ─────────────────────────────────────────
        context = context.transpose(1, 2).contiguous().view(batch, tgt_seq, self.d_model)
        output  = self.W_O(context)

        return output, weights


# ── Demonstration: Visualizing cross-attention alignment ─────────────

src_seq = 6   # Source: "Je suis un étudiant en informatique"
```

```
Concept 5: Masked Multi-Head Attention

Concept 10: Cross-Attention
  Q from decoder, K+V from encoder output
  Bridges encoder and decoder

Concept 3+4: Multi-Head Self-Attention (again, in decoder)
  Same mechanism, different data

                     ──────── ARCHITECTURES ────────────────
Concept 7: Encoder-Decoder (Translation, Summarization, Whisper, DALL-E)
  Encoder:  full bidirectional self-attention
  Decoder:  masked self-attention + cross-attention

Concept 8: Encoder-Only (BERT, RoBERTa — Understanding)
  Only encoder blocks, bidirectional
  [CLS] token for classification

Concept 9: Decoder-Only (GPT, LLaMA — Generation)
  Only decoder blocks, causal
  Autoregressive next-token prediction
```

### 💡 Final Senior Engineer Tips

- **Most production NLP today** uses decoder-only LLMs (GPT-4, LLaMA, Gemini). Encoder-only is better for specialized downstream tasks with labelled data.
- **Cross-attention is everywhere** — diffusion models, video generation (video frames query audio), and robotics (robot state queries instruction embeddings).
- **Flash Attention** (Dao et al., 2022) rewrites the attention computation to avoid materializing the full `seq×seq` matrix — 2-4x faster and memory efficient. Used in all modern LLMs.
- **KV Cache** is what makes LLM inference fast — the K, V matrices from past tokens are cached so we only compute attention for the new token at each step.

## ⚠️ Common Misconceptions

1. **"Attention = full understanding"** — Attention is just a weighted averaging mechanism. Understanding emerges from billions of parameters + vast data, not attention alone.
2. **"Positional encoding is just for RNNs"** — Transformers actually need it MORE since they have zero built-in ordering.
3. **"More heads = better"** — Diminishing returns. 8–16 heads is typical; beyond that, little gain.
4. **"BERT can generate text"** — Encoder-only models like BERT cannot generate. Use a decoder (GPT) for generation.
5. **"The mask is applied to the output"** — The mask is applied to the **attention scores** (before softmax), not the output.
6. **"Cross-attention is only for translation"** — It's everywhere: Stable Diffusion, Whisper, image captioning, DALL-E.
