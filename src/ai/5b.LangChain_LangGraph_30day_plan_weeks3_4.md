### Day 15 — LangGraph Introduction & State Machines

#### Objectives
- Understand why LangGraph exists and when to use it over plain LCEL chains
- Master core concepts: State, Nodes, Edges, Graph
- Build your first stateful graph

#### Why LangGraph?

```
LangChain Chains (LCEL):          LangGraph Graphs:
--------------------------------   -------------------------------------
Linear only: A -> B -> C           Cyclic: A -> B -> C -> A (loops!)
No state persistence               Full state management per thread
No conditional loops               Conditional branching at any point
All-or-nothing execution           Step-by-step with checkpointing
No human-in-the-loop               Interrupts & human approval
Hard to visualize                  Built-in Mermaid diagram export
```

**Use LangGraph when you need:**
- Multi-step agent loops (ReAct, plan-and-execute patterns)
- Human-in-the-loop approval workflows
- Long-running processes that need checkpointing and resumption
- Complex conditional branching logic
- Multi-agent coordination and communication
- Any workflow that is NOT a simple linear pipeline

#### Core Concepts

```python
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage
from typing import TypedDict, Annotated
import operator

# ============================================================
# CONCEPT 1: STATE
# State is a TypedDict that flows through the entire graph.
# Each node RECEIVES the full state and RETURNS a dict of updates.
# Annotations on fields control HOW updates are applied.
# ============================================================

class ChatState(TypedDict):
    # add_messages reducer: new messages are APPENDED to the list
    messages: Annotated[list, add_messages]
    # No annotation = REPLACE on update
    user_name: str
    current_step: str
    iteration_count: int
    is_complete: bool

# ============================================================
# CONCEPT 2: NODES
# Nodes are Python functions: (State) -> dict_of_updates
# They receive the full state and return ONLY what they changed.
# ============================================================

llm = ChatOpenAI(model="gpt-4o")

def chatbot_node(state: ChatState) -> dict:
    """Main chatbot node — calls the LLM with current messages."""
    response = llm.invoke(state["messages"])
    return {
        "messages": [response],         # Appended to messages list
        "current_step": "responded",     # Replaces current_step
        "iteration_count": state["iteration_count"] + 1,
    }

def greeting_node(state: ChatState) -> dict:
    """Personalize the system message using user name."""
    from langchain_core.messages import SystemMessage
    return {
        "messages": [SystemMessage(
            content=f"You are a helpful assistant. The user's name is {state['user_name']}."
        )],
        "current_step": "greeted",
    }

# ============================================================
# CONCEPT 3: EDGES
# Edges define the flow between nodes.
# add_edge(A, B)  = always go from A to B
# add_conditional_edges(A, router_fn) = A to different nodes based on logic
# ============================================================

# ============================================================
# CONCEPT 4: GRAPH ASSEMBLY
# ============================================================

builder = StateGraph(ChatState)

builder.add_node("greeting", greeting_node)
builder.add_node("chatbot", chatbot_node)

builder.add_edge(START, "greeting")          # START -> greeting
builder.add_edge("greeting", "chatbot")      # greeting -> chatbot
builder.add_edge("chatbot", END)             # chatbot -> END

graph = builder.compile()

# ============================================================
# CONCEPT 5: INVOCATION
# ============================================================

initial_state = {
    "messages": [HumanMessage(content="What is Python?")],
    "user_name": "Vidhan",
    "current_step": "starting",
    "iteration_count": 0,
    "is_complete": False,
}

# Full graph execution — returns final state
final_state = graph.invoke(initial_state)
print(final_state["messages"][-1].content)
print(final_state["iteration_count"])   # 1

# Stream step-by-step — see each node's updates
for event in graph.stream(initial_state):
    for node_name, node_output in event.items():
        print(f"=== Node: {node_name} ===")
        print(f"Updated keys: {list(node_output.keys())}")

# Export as Mermaid diagram
print(graph.get_graph().draw_mermaid())
```

#### State Reducer Rules

```python
import operator
from typing import Annotated

# Different reducer behaviors:
class StateExamples(TypedDict):
    # REPLACE (default): new value completely replaces old
    last_answer: str

    # APPEND: add_messages appends new messages, deduplicates by ID
    messages: Annotated[list, add_messages]

    # CONCATENATE: lists joined together from all node updates
    errors: Annotated[list, operator.add]

    # UNION: sets combined
    visited: Annotated[set, lambda a, b: a | b]

    # MAX: keep the maximum value
    max_score: Annotated[int, max]

    # MERGE DICTS: b overrides a
    metadata: Annotated[dict, lambda a, b: {**a, **b}]
```

#### Conditional Edges

```python
from langgraph.graph import StateGraph, START, END
from langchain_core.messages import ToolMessage, SystemMessage
from typing import Literal

# ============================================================
# Pattern 1: Basic Conditional Edge
# The routing function returns a STRING that maps to a node name
# ============================================================

class AgentState(TypedDict):
    messages: Annotated[list, add_messages]
    tool_calls_count: int

def route_after_agent(state: AgentState) -> Literal["tools", "__end__"]:
    """
    Router function — decides which node to visit next.
    Returns: a node name (string) or "__end__" / END to stop.
    """
    last_message = state["messages"][-1]

    # If the LLM made tool calls, execute them
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"

    # Otherwise we're done
    return "__end__"

# ============================================================
# Building ReAct Agent from Scratch with LangGraph
# ============================================================

tools = [search_web, get_stock_data, calculate_tool]
tools_map = {t.name: t for t in tools}
llm_with_tools = ChatOpenAI(model="gpt-4o").bind_tools(tools)

def agent_node(state: AgentState) -> dict:
    """LLM decides: call a tool OR provide final answer."""
    system = SystemMessage(content="""You are a helpful assistant with access to tools.
    Use tools when you need accurate or current information.""")

    response = llm_with_tools.invoke([system] + state["messages"])
    return {"messages": [response]}

def tool_execution_node(state: AgentState) -> dict:
    """Execute all tool calls from the last AI message."""
    last_message = state["messages"][-1]
    tool_results = []

    for tool_call in last_message.tool_calls:
        tool_name = tool_call["name"]
        tool_args = tool_call["args"]
        tool_id = tool_call["id"]

        try:
            result = tools_map[tool_name].invoke(tool_args)
        except Exception as e:
            result = f"Tool error ({tool_name}): {str(e)}"

        tool_results.append(ToolMessage(
            content=str(result),
            tool_call_id=tool_id,
            name=tool_name,
        ))

    return {
        "messages": tool_results,
        "tool_calls_count": state["tool_calls_count"] + len(last_message.tool_calls),
    }

# Build the graph
react_builder = StateGraph(AgentState)
react_builder.add_node("agent", agent_node)
react_builder.add_node("tools", tool_execution_node)

react_builder.add_edge(START, "agent")
react_builder.add_conditional_edges(
    "agent",
    route_after_agent,
    {"tools": "tools", "__end__": END},   # Route map
)
react_builder.add_edge("tools", "agent")   # After tools -> back to agent!

react_agent = react_builder.compile()

result = react_agent.invoke({
    "messages": [HumanMessage(content="Find the latest AI news and give me a 3-point summary.")],
    "tool_calls_count": 0,
})
print(result["messages"][-1].content)

# ============================================================
# Pattern 2: Self-Improvement Loop with Retry
# ============================================================

class QAState(TypedDict):
    question: str
    answer: str
    feedback: str
    attempts: int
    approved: bool

def generate_answer(state: QAState) -> dict:
    prompt = f"""Question: {state['question']}

Previous feedback (if any): {state.get('feedback', 'None — first attempt')}

Provide a comprehensive, accurate answer:"""

    response = llm.invoke([HumanMessage(content=prompt)])
    return {"answer": response.content, "attempts": state["attempts"] + 1}

def evaluate_answer(state: QAState) -> dict:
    eval_prompt = f"""Evaluate this answer:
Question: "{state['question']}"
Answer: "{state['answer']}"

Is it complete and accurate?
Reply "APPROVED" if yes, or provide specific feedback on what's missing."""

    feedback = llm.invoke([HumanMessage(content=eval_prompt)]).content
    approved = "APPROVED" in feedback.upper()
    return {"feedback": feedback, "approved": approved}

def route_after_eval(state: QAState) -> Literal["generate_answer", "__end__"]:
    if state["approved"] or state["attempts"] >= 3:
        return "__end__"
    return "generate_answer"   # Loop: try again with feedback

qa_builder = StateGraph(QAState)
qa_builder.add_node("generate_answer", generate_answer)
qa_builder.add_node("evaluate_answer", evaluate_answer)
qa_builder.add_edge(START, "generate_answer")
qa_builder.add_edge("generate_answer", "evaluate_answer")
qa_builder.add_conditional_edges("evaluate_answer", route_after_eval)
qa_graph = qa_builder.compile()
```

### Day 18 — Human-in-the-Loop Workflows

#### Objectives
- Implement interrupt_before for pre-execution human approval
- Use interrupt() for dynamic in-node approval requests
- Build review-approve-resume workflows for sensitive operations

#### Human-in-the-Loop Patterns

```python
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver
from langgraph.types import interrupt, Command
from typing import Literal

# ============================================================
# Pattern 1: interrupt_before — stop BEFORE a specific node
# ============================================================

class ContentState(TypedDict):
    topic: str
    draft: str
    human_feedback: str
    final_content: str
    approved: bool

def generate_draft(state: ContentState) -> dict:
    prompt = f"Write a detailed blog post about: {state['topic']}"
    draft = llm.invoke([HumanMessage(content=prompt)]).content
    return {"draft": draft}

def apply_feedback_and_publish(state: ContentState) -> dict:
    revision = llm.invoke([HumanMessage(content=f"""
Original draft:
{state['draft']}

Human feedback:
{state['human_feedback']}

Please revise accordingly:""")]).content
    return {"final_content": revision, "approved": True}

builder = StateGraph(ContentState)
builder.add_node("generate_draft", generate_draft)
builder.add_node("apply_feedback", apply_feedback_and_publish)
builder.add_edge(START, "generate_draft")
builder.add_edge("generate_draft", "apply_feedback")
builder.add_edge("apply_feedback", END)

memory = MemorySaver()
workflow = builder.compile(
    checkpointer=memory,
    interrupt_before=["apply_feedback"],   # PAUSE before this node!
)

thread_config = {"configurable": {"thread_id": "content-job-001"}}

# === STEP 1: Run until the interrupt ===
result = workflow.invoke(
    {"topic": "LangGraph for Production", "approved": False},
    config=thread_config,
)
# Graph stops and waits

current = workflow.get_state(thread_config)
print(f"PAUSED at node: {current.next}")   # ('apply_feedback',)
print(f"Draft:\n{current.values['draft'][:300]}")

# === STEP 2: Human reviews and provides feedback ===
human_feedback = "Good draft! Please add a 'Getting Started' section with install commands."

workflow.update_state(
    thread_config,
    {"human_feedback": human_feedback},
)

# === STEP 3: Resume execution from where it stopped ===
final = workflow.invoke(None, config=thread_config)
print(f"Final content: {final['final_content'][:300]}")

# ============================================================
# Pattern 2: interrupt() — Dynamic approval inside a node
# ============================================================

def sensitive_delete_node(state: dict) -> dict:
    """Node that requires human approval before deleting data."""

    # This PAUSES execution and sends the payload to the caller
    human_decision = interrupt({
        "action": f"DELETE all records older than {state['days']} days",
        "estimated_records": 15_000,
        "warning": "This action is IRREVERSIBLE.",
        "prompt": "Type 'APPROVE' to confirm or anything else to cancel.",
    })

    # Execution resumes here when human responds via .invoke(Command(resume=...))
    if human_decision == "APPROVE":
        # Perform the actual deletion
        return {"result": "Deleted 15,000 records", "success": True}
    else:
        return {"result": f"Cancelled by human: {human_decision}", "success": False}

# To resume after an interrupt:
# graph.invoke(Command(resume="APPROVE"), config=thread_config)
# graph.invoke(Command(resume="cancel"), config=thread_config)

# ============================================================
# Pattern 3: Command — Route AND update state simultaneously
# ============================================================

def review_node(state: dict) -> Command:
    """Node that can change routing based on human decision."""

    decision = interrupt({
        "draft": state["draft"],
        "question": "Approve this draft or provide revision feedback?",
    })

    if decision.lower() == "approve":
        return Command(goto="publish_node")   # Approved: go to publish
    else:
        return Command(
            goto="revise_node",
            update={"human_feedback": decision},  # Pass feedback along
        )
```

### Day 19 — Multi-Agent Supervisor Patterns

#### Objectives
- Design supervisor (hub-and-spoke) multi-agent architectures
- Build specialist agents that collaborate on complex tasks
- Implement agent handoff patterns

#### Multi-Agent Architectures

```
Architecture Options:

1. SUPERVISOR (Hub-and-Spoke):
   Supervisor -> routes_to -> Researcher
              -> routes_to -> Coder
              -> routes_to -> Writer
   All agents report back to supervisor for next routing decision.

2. SEQUENTIAL PIPELINE:
   Planner -> Researcher -> Analyst -> Writer

3. PARALLEL + AGGREGATION:
   Researcher ──┐
   Coder       ─┤ -> Aggregator -> Final Response
   Analyst ────┘

4. HIERARCHICAL:
   Supervisor_A -> Sub_Agent_1, Sub_Agent_2
   Supervisor_B -> Sub_Agent_3, Sub_Agent_4
```

```python
from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import create_react_agent
from langchain_core.messages import HumanMessage, AIMessage
from typing import TypedDict, Annotated, Literal

# ============================================================
# Supervisor Multi-Agent Pattern
# ============================================================

class SupervisorState(TypedDict):
    messages: Annotated[list, add_messages]
    next_agent: str

# Create specialist agents using prebuilt create_react_agent
research_agent = create_react_agent(
    llm,
    tools=[tavily_search, wikipedia_tool],
    state_modifier="You are a research specialist. Find accurate, current information. Be thorough.",
)

code_agent = create_react_agent(
    llm,
    tools=[python_repl_tool, file_reader_tool],
    state_modifier="You are a Python coding specialist. Write clean, documented code with examples.",
)

writer_agent = create_react_agent(
    llm,
    tools=[],   # No tools needed — pure writing
    state_modifier="You are a technical writer. Create clear, well-structured documentation.",
)

# Supervisor decides which agent to invoke next
supervisor_prompt = ChatPromptTemplate.from_messages([
    ("system", """You are a project supervisor managing a team of AI specialists:

- researcher: For finding information, facts, current events, research
- coder: For writing code, data analysis, Python scripts
- writer: For creating documents, summaries, reports, documentation
- FINISH: When the entire task is complete and nothing more is needed

Based on the conversation so far, which team member should act NEXT?
Respond with ONLY the name: researcher, coder, writer, or FINISH."""),
    MessagesPlaceholder(variable_name="messages"),
])

supervisor_chain = supervisor_prompt | llm | StrOutputParser()

# Supervisor node
def supervisor_node(state: SupervisorState) -> dict:
    next_agent = supervisor_chain.invoke({"messages": state["messages"]}).strip().lower()
    return {"next_agent": next_agent}

# Worker nodes — each calls its specialist agent
def research_node(state: SupervisorState) -> dict:
    result = research_agent.invoke({"messages": state["messages"]})
    last_msg = result["messages"][-1]
    return {"messages": [AIMessage(content=f"[Researcher]: {last_msg.content}")]}

def code_node(state: SupervisorState) -> dict:
    result = code_agent.invoke({"messages": state["messages"]})
    last_msg = result["messages"][-1]
    return {"messages": [AIMessage(content=f"[Coder]: {last_msg.content}")]}

def writer_node(state: SupervisorState) -> dict:
    result = writer_agent.invoke({"messages": state["messages"]})
    last_msg = result["messages"][-1]
    return {"messages": [AIMessage(content=f"[Writer]: {last_msg.content}")]}

# Router
def route_after_supervisor(state: SupervisorState) -> str:
    agent = state.get("next_agent", "FINISH").strip().lower()
    if agent in ("researcher", "research"):
        return "researcher"
    elif agent in ("coder", "code"):
        return "coder"
    elif agent in ("writer", "write"):
        return "writer"
    return END

# Build supervisor graph
supervisor_builder = StateGraph(SupervisorState)
supervisor_builder.add_node("supervisor", supervisor_node)
supervisor_builder.add_node("researcher", research_node)
supervisor_builder.add_node("coder", code_node)
supervisor_builder.add_node("writer", writer_node)

supervisor_builder.add_edge(START, "supervisor")
supervisor_builder.add_conditional_edges("supervisor", route_after_supervisor)
supervisor_builder.add_edge("researcher", "supervisor")  # Report back!
supervisor_builder.add_edge("coder", "supervisor")
supervisor_builder.add_edge("writer", "supervisor")

supervisor_graph = supervisor_builder.compile()

# Run multi-agent task
result = supervisor_graph.invoke({
    "messages": [HumanMessage(content="""
Task: Research LangGraph, write a Python example that builds a simple agent,
then create a one-page technical summary document.""")],
    "next_agent": "",
})

# Print the full collaborative conversation
for msg in result["messages"]:
    if hasattr(msg, "content"):
        print(f"\n{msg.content[:200]}")
```

### Day 20 — Subgraphs & Graph Composition

#### Objectives

```python
from langgraph.graph import StateGraph, START, END

# ============================================================
# Subgraph: Document Processing Pipeline
# ============================================================

class DocProcessState(TypedDict):
    raw_text: str
    cleaned_text: str
    summary: str
    key_topics: list[str]

def clean_text_node(state: DocProcessState) -> dict:
    cleaned = state["raw_text"].strip().replace("\n\n\n", "\n\n")
    return {"cleaned_text": cleaned}

def summarize_node(state: DocProcessState) -> dict:
    summary = llm.invoke([HumanMessage(
        content=f"Summarize in 2 sentences:\n{state['cleaned_text']}"
    )]).content
    return {"summary": summary}

def extract_topics_node(state: DocProcessState) -> dict:
    topics_text = llm.invoke([HumanMessage(
        content=f"List 5 key topics as a Python list. Example: ['topic1', 'topic2']\n\n{state['cleaned_text']}"
    )]).content
    import ast
    try:
        topics = ast.literal_eval(topics_text.strip())
    except:
        topics = [t.strip() for t in topics_text.split(",")]
    return {"key_topics": topics}

# Build the subgraph
doc_builder = StateGraph(DocProcessState)
doc_builder.add_node("clean", clean_text_node)
doc_builder.add_node("summarize", summarize_node)
doc_builder.add_node("extract_topics", extract_topics_node)
doc_builder.add_edge(START, "clean")
doc_builder.add_edge("clean", "summarize")
doc_builder.add_edge("clean", "extract_topics")   # Parallel from clean!
doc_builder.add_edge("summarize", END)
doc_builder.add_edge("extract_topics", END)

doc_subgraph = doc_builder.compile()

# ============================================================
# Parent Graph that Uses the Subgraph
# ============================================================

class ReportState(TypedDict):
    documents: list[str]
    processed_docs: list[dict]
    final_report: str

def process_all_docs(state: ReportState) -> dict:
    """Process each document through the subgraph."""
    processed = []
    for doc_text in state["documents"]:
        result = doc_subgraph.invoke({"raw_text": doc_text})
        processed.append({
            "summary": result["summary"],
            "topics": result["key_topics"],
        })
    return {"processed_docs": processed}

def generate_report(state: ReportState) -> dict:
    all_summaries = "\n\n".join([
        f"Document {i+1}:\n- Summary: {d['summary']}\n- Topics: {', '.join(d['topics'])}"
        for i, d in enumerate(state["processed_docs"])
    ])
    report = llm.invoke([HumanMessage(
        content=f"Create a comprehensive report from these document summaries:\n\n{all_summaries}"
    )]).content
    return {"final_report": report}

parent_builder = StateGraph(ReportState)
parent_builder.add_node("process_docs", process_all_docs)
parent_builder.add_node("generate_report", generate_report)
parent_builder.add_edge(START, "process_docs")
parent_builder.add_edge("process_docs", "generate_report")
parent_builder.add_edge("generate_report", END)

# OR: Add subgraph DIRECTLY as a node (state keys must overlap)
# parent_builder.add_node("doc_processor", doc_subgraph)

report_graph = parent_builder.compile()

result = report_graph.invoke({
    "documents": [
        "LangChain is a framework for building LLM applications...",
        "LangGraph extends LangChain with stateful, multi-actor graphs...",
    ],
    "processed_docs": [],
    "final_report": "",
})
print(result["final_report"])
```

### Day 21 — Advanced State Management

```python
import operator
from typing import Annotated
from langgraph.constants import Send
from langgraph.types import Command

# ============================================================
# Custom Reducers
# ============================================================

def merge_dicts(a: dict, b: dict) -> dict:
    return {**a, **b}   # b overrides a

class AdvancedState(TypedDict):
    messages: Annotated[list, add_messages]          # APPEND messages
    metadata: Annotated[dict, merge_dicts]           # MERGE dicts
    errors: Annotated[list, operator.add]            # CONCATENATE lists

    return [
        Send("map_summarize", {"document": doc})

map_reduce_builder.add_conditional_edges(START, fan_out_to_documents, ["map_summarize"])
map_reduce_builder.add_edge("map_summarize", "reduce_combine")  # Fan-in
map_reduce_builder.add_edge("reduce_combine", END)
```

```python
from langgraph.graph import StateGraph, START, END
from typing import Literal

class CRAGState(TypedDict):
    question: str
    documents: list
    generation: str
    web_search_needed: bool

def retrieve(state: CRAGState) -> dict:
    docs = vectorstore.similarity_search(state["question"], k=4)
    return {"documents": docs}

def grade_documents(state: CRAGState) -> dict:
    """Grade each doc for relevance using LLM."""
    grade_prompt = ChatPromptTemplate.from_messages([
        ("system", """Grade document relevance to the question.
Return JSON: {"score": "yes"} or {"score": "no"}"""),
        ("human", "Question: {question}\n\nDocument: {document}"),
    ])
    grader = grade_prompt | llm.with_structured_output({"score": str})

    filtered = []
    web_needed = False

    for doc in state["documents"]:
        result = grader.invoke({
            "question": state["question"],
            "document": doc.page_content,
        })
        if result["score"] == "yes":
            filtered.append(doc)
        else:
            web_needed = True   # At least one irrelevant doc -> supplement with web

    return {"documents": filtered, "web_search_needed": web_needed}

def web_search_fallback(state: CRAGState) -> dict:
    """Supplement with web search results."""
    from langchain_community.tools import TavilySearchResults
    results = TavilySearchResults(max_results=3).invoke(state["question"])
    web_docs = [Document(page_content=r["content"]) for r in results]
    return {"documents": state["documents"] + web_docs}

    context = "\n\n".join([d.page_content for d in state["documents"]])
    answer = rag_chain.invoke({"context": context, "question": state["question"]})
    return {"generation": answer}

def route_after_grading(state: CRAGState) -> Literal["web_search", "generate"]:
    if state["web_search_needed"] or not state["documents"]:
        return "web_search"
    return "generate"

crag = StateGraph(CRAGState)
crag.add_node("retrieve", retrieve)
crag.add_node("grade_documents", grade_documents)
crag.add_node("web_search", web_search_fallback)
crag.add_node("generate", generate_answer)

crag.add_edge(START, "retrieve")
crag.add_edge("retrieve", "grade_documents")
crag.add_conditional_edges("grade_documents", route_after_grading)
crag.add_edge("web_search", "generate")
crag.add_edge("generate", END)
```

```python
class SelfRAGState(TypedDict):
    question: str
    documents: list
    generation: str
    hallucination_grade: str   # "yes" (grounded) / "no" (hallucinated)
    quality_grade: str         # "yes" / "no" / "partial"
    iterations: int

def grade_hallucination(state: SelfRAGState) -> dict:
    """Is the generation factually grounded in retrieved documents?"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """Is this answer FULLY supported by the documents?
Return JSON: {"score": "yes"} if grounded, {"score": "no"} if hallucinated."""),
        ("human", "Documents:\n{docs}\n\nAnswer: {generation}"),
    ])
    grader = prompt | llm.with_structured_output({"score": str})
    docs_text = "\n".join([d.page_content for d in state["documents"]])
    result = grader.invoke({"docs": docs_text, "generation": state["generation"]})
    return {"hallucination_grade": result["score"]}

def grade_quality(state: SelfRAGState) -> dict:
    """Does the answer actually resolve the user's question?"""
    prompt = ChatPromptTemplate.from_messages([
        ("system", """Does this answer fully resolve the question?
Return JSON: {"score": "yes"}, {"score": "partial"}, or {"score": "no"}"""),
        ("human", "Question: {question}\n\nAnswer: {generation}"),
    ])
    grader = prompt | llm.with_structured_output({"score": str})
    result = grader.invoke(state)
    return {"quality_grade": result["score"]}

def route_after_hallucination(state: SelfRAGState) -> str:
    if state["hallucination_grade"] == "yes":
        return "grade_quality"    # Not hallucinated -> check quality
    elif state["iterations"] < 3:
        return "generate"         # Regenerate with same docs
    return "__end__"              # Give up after 3 tries

def route_after_quality(state: SelfRAGState) -> str:
    if state["quality_grade"] == "yes":
        return "__end__"          # Good answer!
    elif state["iterations"] < 3:
        return "retrieve"         # Re-retrieve with different approach
    return "__end__"              # Give up after 3 tries

self_rag = StateGraph(SelfRAGState)
self_rag.add_node("retrieve", retrieve_node)
self_rag.add_node("generate", generate_node)
self_rag.add_node("grade_hallucination", grade_hallucination)
self_rag.add_node("grade_quality", grade_quality)

self_rag.add_edge("retrieve", "generate")
```

```python
# ── Rate Limiter ───────────────────────────────────────────────────────────────
class RateLimiter:
    def __init__(self, max_requests: int = 10, window_seconds: int = 60):
        self.max_requests = max_requests
        self.window = window_seconds
        self.requests: dict = defaultdict(list)

    def is_allowed(self, user_id: str) -> bool:
        now = time.time()
        self.requests[user_id] = [r for r in self.requests[user_id] if now - r < self.window]
        if len(self.requests[user_id]) >= self.max_requests:
            return False
        self.requests[user_id].append(now)
        return True
```

### Day 30 — Capstone: Production AI Assistant

#### Full Production System

```python
"""
CAPSTONE: Multi-Tenant Production AI Assistant

Features:
- RAG over company documentation
- Real-time web search fallback
- Multi-turn memory per user session (PostgreSQL)
- Human-in-the-loop for destructive actions
- Streaming responses via FastAPI + SSE
- Full observability via LangSmith
- Rate limiting and JWT authentication
"""
import os, uuid, time, json
import operator
from typing import TypedDict, Annotated, Literal
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.vectorstores import Chroma
from langchain_core.tools import tool
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.postgres import PostgresSaver
from langgraph.prebuilt import ToolNode

# ── State ──────────────────────────────────────────────────────────────────────
class AssistantState(TypedDict):
    messages: Annotated[list, add_messages]
    user_id: str
    session_id: str
    user_plan: str
    tools_used: Annotated[list, operator.add]

# ── Knowledge Base ─────────────────────────────────────────────────────────────
embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
knowledge_base = Chroma(
    persist_directory="./kb",
    embedding_function=embeddings,
)

# ── Tools ──────────────────────────────────────────────────────────────────────
@tool
def search_knowledge_base(query: str) -> str:
    """Search internal documentation and knowledge base.
    Use this FIRST for product questions, company info, and policies.
    
    Args:
        query: Search query string
    """
    docs = knowledge_base.similarity_search(query, k=4)
    if not docs:
        return "No relevant documentation found for this query."
    return "\n\n---\n\n".join([
        f"[{d.metadata.get('source', 'Internal Doc')}]\n{d.page_content}"
        for d in docs
    ])

@tool
def search_web_current(query: str) -> str:
    """Search the web for current information not in the knowledge base.
    Use when the question is about recent events or things not in internal docs.
    
    Args:
        query: Web search query
    """
    from tavily import TavilyClient
    results = TavilyClient(api_key=os.getenv("TAVILY_API_KEY")).search(
        query, max_results=3
    )
    return "\n\n".join([r["content"] for r in results.get("results", [])])

@tool
def create_support_ticket(issue: str, priority: str) -> str:
    """Create a human support ticket for issues requiring human attention.
    ONLY use when the user explicitly asks to escalate or contact support.
    
    Args:
        issue: Clear description of the issue
        priority: 'low', 'medium', 'high', or 'critical'
    """
    ticket_id = f"TKT-{abs(hash(issue + priority)) % 100000:05d}"
    return f"Support ticket {ticket_id} created ({priority} priority). A human agent will respond within 4 business hours."

tools = [search_knowledge_base, search_web_current, create_support_ticket]
tool_node = ToolNode(tools)

# ── LLM ───────────────────────────────────────────────────────────────────────
llm = ChatOpenAI(model="gpt-4o", temperature=0.1, streaming=True)
llm_with_tools = llm.bind_tools(tools)

# ── Nodes ─────────────────────────────────────────────────────────────────────
def inject_system_context(state: AssistantState) -> dict:
    """Inject personalized system prompt based on user context."""
    system = SystemMessage(content=f"""You are a helpful AI assistant for AcmeCorp.

User Plan: {state['user_plan']}
User ID: {state['user_id']}

Guidelines:
1. Search the knowledge base FIRST for product and company questions
2. Use web search ONLY for current events or information not in the KB
3. Create support tickets ONLY when explicitly requested
4. Be concise, professional, and friendly
5. Always cite your source (knowledge base article or web URL)
6. If unsure, say so rather than guessing""")

    return {"messages": [system]}

def agent_respond(state: AssistantState) -> dict:
    """Main agent node — decides to use tools or respond directly."""
    response = llm_with_tools.invoke(state["messages"])
    used_tools = [tc["name"] for tc in (response.tool_calls or [])]
    return {"messages": [response], "tools_used": used_tools}

def should_use_tools(state: AssistantState) -> Literal["tools", "__end__"]:
    last = state["messages"][-1]
    if hasattr(last, "tool_calls") and last.tool_calls:
        return "tools"
    return "__end__"

# ── Graph ──────────────────────────────────────────────────────────────────────
builder = StateGraph(AssistantState)
builder.add_node("inject_context", inject_system_context)
builder.add_node("agent", agent_respond)
builder.add_node("tools", tool_node)

builder.add_edge(START, "inject_context")
builder.add_edge("inject_context", "agent")
builder.add_conditional_edges("agent", should_use_tools)
builder.add_edge("tools", "agent")

# ── Production Deployment ──────────────────────────────────────────────────────
conn_str = os.environ.get("POSTGRES_URI", "postgresql://localhost/langgraph")
checkpointer = PostgresSaver.from_conn_string(conn_str)
checkpointer.setup()

assistant = builder.compile(checkpointer=checkpointer)

# ── FastAPI Server ─────────────────────────────────────────────────────────────
from fastapi import FastAPI, Depends
from fastapi.responses import StreamingResponse
from pydantic import BaseModel

api = FastAPI(title="AcmeCorp AI Assistant", version="1.0.0")

class ChatRequest(BaseModel):
    message: str
    session_id: str | None = None

@api.post("/api/v1/chat/stream")
async def stream_chat(request: ChatRequest, user: dict = Depends(get_current_user)):
    session_id = request.session_id or str(uuid.uuid4())
    config = {"configurable": {"thread_id": f"{user['id']}:{session_id}"}}

    async def generate():
        async for event in assistant.astream_events(
            {
                "messages": [HumanMessage(content=request.message)],
                "user_id": user["id"],
                "session_id": session_id,
                "user_plan": user.get("plan", "standard"),
                "tools_used": [],
            },
            config=config,
            version="v2",
        ):
            if event["event"] == "on_chat_model_stream":
                token = event["data"]["chunk"].content
                if token:
                    yield f"data: {json.dumps({'type': 'token', 'content': token})}\n\n"
            elif event["event"] == "on_tool_start":
                yield f"data: {json.dumps({'type': 'tool', 'name': event['name']})}\n\n"

        yield f"data: {json.dumps({'type': 'done', 'session_id': session_id})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"})

@api.get("/health")
async def health():
    return {"status": "healthy", "version": "1.0.0"}
```

## Quick Reference Cheat Sheet

### LCEL Patterns

```python
# Sequential
chain = prompt | llm | parser

# Parallel
chain = RunnableParallel(a=chain_a, b=chain_b)

# Add keys
chain = RunnablePassthrough.assign(key=fn_or_chain)

# Route
chain = RunnableBranch((condition, chain_a), chain_b)

# Fallback
chain = primary.with_fallbacks([backup1, backup2])

# Retry
chain = chain.with_retry(stop_after_attempt=3)
```

### LangGraph Patterns

```python
# Build graph
builder = StateGraph(MyState)
builder.add_node("name", fn)
builder.add_edge(START, "name")
builder.add_conditional_edges("name", router_fn, {"a": "node_a", "b": END})
graph = builder.compile(checkpointer=MemorySaver())

# State reducers
messages: Annotated[list, add_messages]   # Append
errors:   Annotated[list, operator.add]   # Concatenate
score:    Annotated[int, max]             # Keep max

# Human-in-the-loop
graph = builder.compile(interrupt_before=["sensitive_node"])
graph.update_state(config, {"human_decision": "APPROVE"})
graph.invoke(None, config=config)   # Resume
```

### When to Use What

| Situation | Solution |
|---|---|
| Simple Q&A chatbot | `ChatOpenAI` + `ChatPromptTemplate` + `StrOutputParser` |
| RAG over documents | `Chroma` + `retriever` + RAG chain |
| Single tool-using agent | `create_react_agent` |
| Complex multi-step workflow | `StateGraph` with nodes & conditional edges |
| Long-running resumable task | `StateGraph` + `PostgresSaver` |
| Human approval required | `interrupt_before` or `interrupt()` |
| Multiple collaborating agents | Supervisor graph pattern |
| Streaming to browser | `astream_events()` + FastAPI SSE |
